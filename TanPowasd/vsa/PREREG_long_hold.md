## 1. 数据规格（生成器在本文件提交之后才写）
- **生成方式：零 LLM、零 key**。crossproj-zh 原生成器用 LLM 渲染对话（`DATACARD.md`），本集不复用它，改为**程序模板生成**（固定随机种子，确定性）：
  手写真值世界（一人、六个并行项目）→ 程序把事实写进短轮与长文档（会议纪要 / 施工日志 / 学习日志 / 陪护日志等，以用户粘贴给助手的一整轮出现）→ 程序出题、回填金标 dia_id。
  LLM 调用数计划 = 0（若不得不用，上限 150，按用户 2026-10-18 授权只用于生成 / 校验）。
- **格式**：与 crossproj-zh 相同的 LoCoMo 风格 `[{sample_id, conversation{speaker_a, speaker_b, session_N, session_N_date_time}, qa[...]}]`，
  `dia_id = DN:k`，每题 `evidence` / `evidence_groups`（植入轮 + 该版本有效期内原样复述同一取值的轮），评分用 crossproj-zh 的 `score.py`（r@10）。
- **写入单元口径**：同 `seg_real.cp_elems`（每轮一个单元，含 v2 角色；会话日期作 SESSION 与相对时间基准）；长单元 = `seg.n_items` > K_MAX（= `long_count.py` 口径）。
- **规模（读数前定死）**：约 44 场会话；长文档 ≥ 90 篇（每篇一轮）。
- **题目（共 200，读数前定死）**：
  - 检索题（非时间题）120：短轮事实 50、长文档内事实 50、更新后最新值 20（证据短轮 10 / 长文档 10）。问句不得命中 `real_v2.ZH_TIME_Q`。
  - 时间题 80，问句一律用「哪一天」（命中 `ZH_TIME_Q`，粒度 = 日），金标 `YYYY年M月D日`，须被 `real_v2.canon_zh` 解析为 `DATE:YYYY-MM-DD`：
    - (a) 短轮事件日期 30：用户在一个短轮里说「M月D日 … 做了某事」；
    - (b) 长文档日期 30：问「某决定 / 某记录是在哪一天的纪要 / 日志里定下的」，金标 = 该文档抬头日期（纪要 / 日志惯例：抬头写日期；文档可在会话日期之后 0–3 天才粘贴，故会话日期不一定等于金标）；
    - (c) 长文档正文内日期 20：问文档正文中某条截止 / 约定日期（不是抬头日期）。
    （推断：在 v2 时间规则「每单元只取最先出现的日期」口径下，(c) 对两臂都难；保留它是为了不把数据只造成有利于 L1 的形状。）
  - 时间题同样计入 E1（与 cp_rows 口径一致：全部有证据的题）。
- **结构校验（造完、冻结前，只做这些，不跑任何检索 / 解绑）**：长单元数（long_count 口径）≥ 60；时间题 80 道金标全部可被 canon_zh 解析；检索题 120 道全部不命中 ZH_TIME_Q；
  每题证据 dia_id 存在；每个时间题证据轮的类型与 (a)(b)(c) 一致（(a) 在短单元、(b)(c) 在长文档轮）。
  若长单元数 < 60，只允许加长文档（增加每篇条目数）后重新生成并重验，**不改题目、不看任何算法输出**；改动写入数据卡。
- **冻结**：结构校验通过后写 `release/SHA256SUMS.json` 并提交推送；读数脚本对 sha256 硬核对，不符即停。

## 2. 读数（只跑一次：`vsa/long_hold.py --run`；已有结果即拒跑）
- **E1**：VSA 检索 r@10（score.py evidence_groups 口径，`seg_real.cp_rows`），全部 200 题，L1 vs S0 配对符号检验，双侧 α=.05。
- **E2**：时间题解绑（阶段 2 A3 配置：te10 候选 → 其痕迹解绑；`real_v2.answer_time` + `granularity`；单元跨多块时按写入序逐块取第一个非存疑），
  判对 = 预测 == `canon_zh(金标)`（同 PerLTQA E2 口径）。te10 候选：同 `run_umb.py` LoCoMo 记忆集 te 口径（`bench_cc.build(轮, None, 会话号)` + `tree.build(**ARMS["TE"])`、`LEX_RM3=0`、`dedup` 回轮），
  在冻结之后、同一次运行里现算，S0 / L1 共用同一候选（候选与 VSA 无关）。说话人过滤名单为空（问句不点名说话人）。McNemar（`real_v2.mcn`），双侧 α=.05。
- **E3（描述性，不入判定）**：长单元数、块数、块最大项数、拒写数（S0 / L1）；E2 按 (a)(b)(c) 分型的描述性拆分。
- **事先已知（推断）**：E1 上 L1 与 S0 的差异只能来自长单元写成多条痕迹 + 库级统计（idf 文档数、RI 共现窗口、码本）变化（同 PREREG_long §3 存疑项），预期接近打平。

## 3. 功效估算（推断，读数前写定）
- E2：PerLTQA dev 上 54 题里 10 题不一致（18.5%，全为 L1 胜）。本集 80 道时间题中 60 道证据在长文档（S0 必拒写该单元），
  若不一致率 ≥ 15% ⇒ 约 12 题不一致，符号检验需 ≥ 10/12 胜才 p<.05；若全为 L1 胜，6/0 即 p=.031。80 题足以检出 PerLTQA 量级的效应；
  若效应只有其一半（约 6 题、5/1），则检不出（p=.22）——这是本集的检出边界。
- E1：200 题，只用于「不降」检查；PerLTQA dev E1 为 9/9 打平，预期本集同样以平局为主。

## 5. 独立性边界（存疑，如实写入结果）
- 生成器与 crossproj-zh **同源（存疑）**：同一设计者 / 同一格式与评分器、同一「一人多项目」叙事范式；本集模板由实现 L1 的同一方编写，
  编写者知道 L1 的机制（长单元按 K_MAX 分块、TIME 取单元内最先出现的日期）。数据设计（纪要抬头写日期）虽是常见惯例，但可能偏向 L1（存疑）。
- 模板生成的中文比 LLM 渲染的对话更规整、复述更少，检索可能偏易或偏难（存疑）；单人物、单一叙事，题目间不独立（有效样本量小于题数）。
- 因此本集通过只能算「在一份独立性有限的保留集上确认」，不等于在外部真实数据上确认。
