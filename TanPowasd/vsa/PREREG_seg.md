## 1. 切分规则（唯一自由参数 θ_seg）
输入是写入顺序的句流（LoCoMo/hive 每轮一句流元素；PerLTQA 长单元先按句号/问号/换行切句）。对第 t 个元素：
```
o_t   = Jaccard(内容词集_t ∪ 实体集_t , 内容词集_{t-1} ∪ 实体集_{t-1})      # 停用词表沿用 memory.tokens
μ_t   = 最近 m=5 个 o 的均值（段内；段首不足 5 个用已有的）
边界 ⇔ o_t < θ_seg · μ_t   或   会话日期变化   或   说话场景变化（会话号/章节号变化）   或   段内叠加项数 + 新项 > K_MAX
```
- m=5、K_MAX=221 固定，不调。
- 段 = 一条痕迹：T_seg = Σ 成员轮的 角色⊗填充 + 词袋（同阶段 2 编码）；保留成员轮 id 列表。
- **白箱边界**：任何一段都不超过 K_MAX（I3 不变量照旧，超限时强制切，不静默丢弃）。

## 2. 对照臂
| 臂 | 写入单位 |
|---|---|
| S0 | 阶段 2 原样：逐轮/逐单元，超 K_MAX 拒写 |
| S1 | 固定长度：按写入顺序装句，装满 K_MAX 或会话变化即切（无话题断层） |
| S2a/b/c | 事件切分，θ_seg ∈ {0.3, 0.5, 0.7}（三个候选，读数前定死） |

S1 是关键对照：S2 只有胜过 S1 才说明「按断层切」有用，而不只是「能装下」。

## 3. 读数口径（命中按轮计，保证与 S0 可比）
检索：查询对段痕迹打分 → 段按分排序 → 段内成员轮按各自阶段 2 单轮分排序展开 → 取前 10 轮算 r@10。
- **E1 主读数**：VSA 检索 r@10（轮级），dev 集：LoCoMo dev、hive dev、PerLTQA dev、crossproj-zh dev（44 题，按 evidence_groups，用其 score.py）。
- **E2**：时间题解绑 J2（阶段 2 判定不变）——LoCoMo dev 50 题、PerLTQA dev 54 题；te10 候选轮 → 其所在段痕迹解绑。
- **E3 描述性**：段数、段长分布、被强制切（K_MAX）的段数、PerLTQA 拒写数（S0 应为 347，S1/S2 应为 0）。
- 显著性：配对符号检验 / McNemar，双侧 α=.05。

## 4. dev 选臂规则
1. 先在 S2a/b/c 中选 E1 四集宏平均最高者为 S2*。
2. S2* 进入保留集确认的条件：E1 宏平均 > S1 且 > S0；且无一 dev 集相对 S0 显著倒退。
3. 否则结论为「事件切分无增益」，不碰保留集。

## 6. 采纳规则（用户 2026-10-16 规则）
保留集上 S2* 相对 S0：各集均值不降、至少一集上升（reuse 答案按其阈值机制读）。满足则 S2* 成为 VSA 默认写入方式；否则 S0 不变。
- 推断风险：段内多轮共享一条痕迹，效果近似「邻轮聚合」，NC 在 TMD 上正是这样倒退（−.073）。若 TMD 再倒退，结论按规则拒绝，不再换 θ 重问。
