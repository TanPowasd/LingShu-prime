## 2. 机制一：跨候选置信度比较

### 2.0 L1 现行规则的形式化（`real_v2.answer_time`，不动）
设 te10 候选序 c₁…c₁₀，`d(c)` = `Memory.decode_unit(c, TIME)`（按块写入序取第一个边距 ≥ MARGIN_MIN 的填充，否则存疑）。
**L1 选答 = 最小的 i 使 d(cᵢ) 非存疑；全存疑 ⇒ c₁ 的 SESSION；再存疑 ⇒ 存疑。**「存疑落到下一候选」在 L1 下有两种来源，可由写入角色**审计**（不看金标）：
- **无 TIME 存疑**：cᵢ 各块都没有 TIME 项，清理边距只是噪声；
- **干扰存疑**：cᵢ 某块角色并集含 ≥ 2 个不同 TIME 填充（THEORY §7.2 / 方案 v0.1 §1.3：m=2 时约 84% 存疑）。

dev 读出（`l1_formal`）：

| 集 | L1 对 | 第 1 候选即答 | 经「无 TIME 存疑」落下 | **经「干扰存疑」落下** |
|---|---:|---:|---:|---:|
| PerLTQA | 18/54 | 15（全为 first 类） | 0 | **3**：first 2（`冯伟#events#191`、`韩刚#events#80`，均落到证据单元）+ body 1（`徐佳#dialogues#145`，落到**非证据** u29，其首日期恰为 2015 ⇒ 巧合答对） |
| LoCoMo | 28/50 | 20 | 8 | 0（无长单元、无多 TIME 块） |

⇒ **L1 first 类 17/20 中，2 题靠「另一个单元的干扰存疑」碰对**（另有 body 类 1 题是落到非证据单元的巧合）。这 3 题正是 BD 的潜在伤害面：BD 把干扰单元拆成每句一个 TIME，干扰存疑消失。

### 2.1 可选规则（只作用于 BD 臂；无子痕迹的候选一律 ≡ L1）

**X1　L1 存疑者仍存疑**（「BD 只换日期、不换候选」）
- 规则：候选 c 若 d(c) 存疑 ⇒ 不论 BD 子痕迹给出什么，c 视为存疑；d(c) 非存疑且 c 有子痕迹 ⇒ 用 BD 选句结果替换 c 的日期。⇒ BD 选中的候选**恒等于** L1 选中的候选。
- 显式条件：只看 `decode_unit` 的存疑判定，无新阈值。
- dev：PerLTQA **18/54，与 L1 逐题完全相同（0 题改变）**——修好 ①②（3 题），但把 BD 的 2 道改对（`孙晓明#dialogues#149`、`龙美丽#events#47`）也一并退回。原因：dev 里被 te10 碰到的 BD 启用单元几乎都是 L1 干扰存疑单元（PerLTQA 口径「每句一个 TIME、块 = 句角色并集」），X1 把它们全部关掉。
- 风险 / 推断：在 crossproj / LoCoMo 口径的长单元上（`seg_real.cp_elems`：整单元抽角色、TIME 只挂首块 ⇒ L1 首块单 TIME、非存疑），X1 不挡 BD（推断，由代码读出，未读保留集）；即 X1 = 「BD 只对表头式口径生效，对 PerLTQA 式多 TIME 块不生效」。等价于在真实对话体上放弃正文日期。

**X2　单元内选句边距（「选句存疑」，I7 在选句层的类比）**
- 规则：BD 在候选 c 内选中句 s（首个解绑非存疑者）；令 s′ = c 内**填充与 s 不同**的子痕迹中 `qcos` 最高者；若 `qcos(s) − qcos(s′) < δ` ⇒ c 存疑，落到下一候选。
- 显式条件：δ 必须先验给出。现有理论只给了解绑边距的尺度（MARGIN_MIN = 2/√D），**没有** RI 余弦（`qcos`）的噪声尺度；δ 若取 dev 观察值即为调参（存疑）。
- dev（描述性，δ ∈ {.02, .05, .10}）：δ=.05/.10 只修 `冯伟#events#191`（u64 两句 .163 vs .138），修不了 `韩刚#events#80`（.415 vs .274），且**伤** `孙晓明#dialogues#149`（.328 vs .312 ⇒ 存疑落到错候选）。PerLTQA 17/54，1 胜 2 负 vs L1。
- 风险：在同一单元里有多个日期、问句与多句都相关时（对话体常见）大量变存疑；把 L1 的「多 TIME ⇒ 存疑」原样搬到选句层，等于部分撤销 BD。

**X3　全候选比较（取作答句余弦最大者）**（已诊断，**不推荐**，列出以示排除）
- 规则：te10 里所有非存疑候选各出一个答案，取「作答句余弦」最大者（BD 候选用子痕迹 `qcos`，L1 候选用 `ucos`）。
- dev：PerLTQA 16/54，3 胜 5 负；first 类伤 4 题（`何峰#events#77`、`田洋#dialogues#261`、`田洋#events#138`、`韩刚#events#80`）。LoCoMo 29/50（1 胜 0 负）。
- 风险：句级余弦与单元级余弦尺度不同（短句余弦系统性偏高），比较不公平；且改动 L1 在短单元上的行为（LoCoMo 变化），违背「仅长单元」。

**X4　抢答需胜过 L1 落点（同尺度 `ucos` 比较）**　← 推荐候选
- 规则：沿 te10 序扫描；候选 c 有子痕迹且 BD 给出非存疑答案时：
  - 若 d(c) **非存疑** ⇒ 照 BD（与 v0.1 同）；
  - 若 d(c) **存疑**（L1 本会跳过 c）⇒ 令 j = c 之后第一个 d 非存疑的候选（= L1 的落点）；**仅当 `ucos(c) ≥ ucos(j)`（或无 j）才由 c 的 BD 答案抢答**，否则 c 视为存疑，继续扫描。
- 显式条件：比较双方都是**单元级** VSA 余弦（同一 `Memory.search_many`、同一 β=0.5、同一 idf / RI 投影），无新阈值；平局取 c（稳定）；te10 序本身来自外部检索（`te.json`），X4 只在 L1 会「越过」c 时才引入 VSA 自身的单元相关度作仲裁。
- dev：PerLTQA **19/54，2 胜 1 负 vs L1**；修好 ①（`冯伟` u64 .142 < u40 .290；`韩刚` u55 .226 < u32 .269），保住 BD 两道改对（`孙晓明` u51 .400 > .226；`龙美丽` u23 .234 > .198）；剩下的 1 负 = ② 回声（`徐佳`，u51 .371 > .230，X4 放行后在 u51 里选中提问句），由机制二处理。LoCoMo 0 变化（无子痕迹）。
- 风险：
  - **事后性最强**：X4 的比较方向正是从这 4 道题里读出来的（存疑，必须在未见过的数据上验证）；
  - te10 的外部排序与 VSA `ucos` 不一致本身是常态（如 `冯伟` 第 1 候选 `ucos` 只排第 7）；X4 等于「L1 存疑时让 VSA 相关度否决外部排序第一」，若外部检索更准，X4 会把真证据单元的正文日期挡掉（推断）；
  - 只在 PerLTQA 式多 TIME 块（L1 干扰存疑）上起作用；表头式口径不触发（推断，同 X1）。

## 3. 机制二：问句回声抑制（单元内选句层）

### 3.0 白箱度量（`bd_v02_diag.py: norm / bigrams / echo_j / echo_c / IS_Q`）
- 规范化：去句首说话人前缀 `^[^\s:：]{1,16}[:：]\s*`，只留汉字 / 拉丁字母 / 数字（小写）。
- **回声度 J** = 字符二元组 Jaccard(句, 问句) ∈ [0,1]（对称；长句不因「覆盖了问句」而得高分）。备选 **C** = |句∩问| / |问|（覆盖率）。
- **问句形**：`[？?]\s*$|[吗呢么]\s*[？?。！!]?\s*$`（句末疑问标点或疑问语气词）。
- **无本句日期**：子痕迹类型 ∈ {`inherit`, `pre`}（日期是继承来的，不是句子自己说的）。
- 理论依据：一条「问句形且无本句日期」的子痕迹**没有陈述任何日期**，它带的 TIME 只是锚点继承（B-iii 规则 5）；它与问句同文，会被余弦选中，却从结构上不可能是答案的出处。

### 3.1 可选规则
**E1　纯相似度门槛**：J ≥ τ ⇒ 该子痕迹不参与选句。
- dev：τ ∈ {.3,.4,.5} 修 `徐佳#145`、零伤；τ=.6 修不了（徐佳 J=.567）。**C 版误伤** `龙美丽#events#47`：含答案的陈述句复述了问句（C=.545，J=.146）——覆盖率度量会把「复述问题的回答」当回声。⇒ 若用相似度，只用对称的 J。
- 风险：无语用条件，回答句若几乎照抄问句（「《时间之舞》是在 2015 年拍摄的」）也可能 J 高——但此类句有本句日期，E2 的条件会放过它，E1 不会。

**E2　J ≥ 0.5 且问句形且无本句日期 ⇒ 跳过**　← 推荐候选
- τ = 0.5 取先验含义（问句与该句过半二元组相同），不取 dev 最优点（dev 上 .3–.5 均同）。
- dev：修 `徐佳#145`、零伤；波及面极窄——PerLTQA te10 内 1551 条（题 × 子痕迹）中只标记 **2** 条（徐佳 .567、许慧#d261 .80）。
- 已知漏网（描述性）：`田洋#dialogues#210` 的回声提问句 J=.476 未达 .5（该题 L1、BD 都错，不影响对错）；`韩刚` 泛问句「活动的时间是什么时候呢？」J=.18 不会被 E2 标记——它由机制一 X4 挡下。
- 全部子痕迹都被标记 ⇒ 显式回退 `decode_unit`（来源 `fallback_echo`，计数上报，不静默）。

**E3　E2 的条件 + 「改取下一句」**：被标记的提问句改由句序上其后第一个未标记子痕迹代替（问—答结构里的回答）。
- dev：与 E2 结果相同（徐佳的回答句恰在下一句）。
- 风险：依赖「答在下一句」的对话体假设；表格 / 日志体里下一句与提问无关时会静默选错（推断）。比 E2 多一条结构假设，收益在 dev 上不可区分 ⇒ 不推荐作首选。

**E4　问句形且无本句日期 ⇒ 跳过（无相似度门槛）**
- 最「无参」：直接按 3.0 的理论依据，所有不陈述日期的提问句都不作选句候选。
- dev：单用时修 `徐佳#145`（但不修 ①，first 类仍伤 2 题）；与 X4 组合时 20/54，2/0。
- 风险：**波及面大**——PerLTQA te10 内 1551 条中标记 **328 条（21%）**；会改变大量单元内的选句（dev 上表现为 `韩刚#dialogues#198` 改答另一个错日期），在未见数据上的行为最难预估（存疑）。
