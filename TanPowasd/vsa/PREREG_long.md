# PREREG_long：VSA 长单元分块写入（只切超 K_MAX 的单元）· v0.1（读数前写定）

> 来源：`RESULTS_seg.md` 诚实结论第 3 条——PerLTQA 时间解绑的容量瓶颈可由 S1 式 K_MAX 分块解决（E2 .148→.352，11/0 p=.001），
> 但 S2 把短单元也切碎导致 E1 显著倒退；建议「只对超 K_MAX 的单元做 S1 分块，短单元原样」另起预注册。
> 状态：用户 2026-10-21 18:21「试试」批准方案；本文件先于实现与任何读数单独提交。SPDX: LicenseRef-TanPowasd-Proprietary

## 1. 规则（无自由参数）
对每个写入单元 u（LoCoMo / crossproj 一轮、hive 一块、PerLTQA 一个单元、KMB / TMD 一条），k_u = 其 S0 痕迹叠加项数（`seg.n_items`，即 角色⊗填充 ∪ 词袋 去重并集）：
- **k_u ≤ K_MAX（短单元）**：原样逐单元写入，载荷（词序列、角色）与 S0 逐位相同。
- **k_u > K_MAX（长单元）**：取 `seg_real.py` 中该单元的元素序列（与 S1 的输入完全相同：PerLTQA 切句、每句 TIME = 句中最先出现的日期；其余集若出现则按 `seg.make_elems` 的强制切片），
  按写入序贪心装块：块内叠加项并集 ∪ 下一元素项 > K_MAX 即另起一块（= S1 在单元内的行为；块不跨单元）。块载荷 = `seg.seg_payload`（成员词按序拼接、角色去重并集，同 S1）。
- 检索与展开同 seg 口径：查询对每条痕迹（短单元 / 块）打分 → 降序 → 块成员展开回其源单元（同一单元多块共享单元号，去重保序）。
- K_MAX=221（`hdc.k_max()`，D=10000、N=1000、ε=1e−3）固定。

## 3. 读数（dev，与 PREREG_seg §3 及其口径澄清 1–9 完全相同）
- **E1**：VSA 检索 r@10（轮级 / 单元级展开）：LoCoMo dev 257、hive dev 46（8000 字预算证据句完整率）、PerLTQA dev 3956、crossproj-zh dev 41（evidence_groups，score.py）。配对符号检验，双侧 α=.05。
- **E2**：时间题解绑（阶段 2 A3 配置；te10 候选 → 其痕迹解绑；单元跨多块时按写入序逐块取第一个非存疑）：LoCoMo dev 50 题 J2、PerLTQA dev 54 题规范形相等。McNemar，双侧 α=.05。
- **E3（描述性）**：长单元数、块数、块最大项数、拒写数（S0 / L1）。
- **事先已知**（不是读数，由 `results/seg_dev.json` E3 的 S0 最大项数推出）：LoCoMo（52）、hive（174）、crossproj-zh dev（110）没有长单元 ⇒ L1 在这三集上必然与 S0 逐位相同，
  只有 PerLTQA dev（346 个长单元）能提供证据。读数脚本对「无长单元」的检索单元在运行时断言 L1 排序 ≡ S0 排序（白箱，不静默）。
- **存疑 / 推断**：在含长单元的检索单元里（PerLTQA 的某些角色、KMB、TMD），短单元的载荷与 S0 逐位相同，但**库级统计**会变：idf 的文档数 N 与 df（块按文档计）、
  RI 共现窗口（块边界处断开）、清理码本（块里多出的句级 TIME 填充）。因此这些检索单元里短单元的分数 / 解绑可能与 S0 有细微差异——这是「把长单元写成多条痕迹」的固有后果，不另设开关去掉。

## 4. dev 门槛（进入保留集的条件）
1. 无一 dev 集相对 S0 显著倒退（E1 四集符号检验、E2 两集 McNemar，任一「显著且负多于胜」即不过）；
2. 且 E1 或 E2 至少一集相对 S0 显著上升。
否则结论「长单元分块在 dev 上不合格」，不碰保留集。

## 7. 守卫与定点变异（实现后、读数前：守卫全绿；旧 26 条 + 新变异全部变红）
- **G21 短单元 ≡ S0**：全短单元库上 L1 载荷、每题分数、排序、时间解绑与 S0 逐位相同；混合库上每个短单元的载荷行与 S0 行逐位相同、恰占一条痕迹；
  项数**恰为 K_MAX** 的单元必须按短单元处理（S0 在 = K_MAX 时不拒写）。
- **G22 块边界**：长单元每块 ≤ K_MAX、至少 2 块、块不跨单元、块成员按写入序连续、块并集 = 该单元全部元素项（不丢项）、贪心极大（每块 ∪ 下一块首元素 > K_MAX）；含恰好装到 K_MAX 的边界定例。
- **G23 块展开**：同一长单元的多块共享单元号、展开后每单元恰出现一次；只命中长单元末块的查询须把该单元排第一。
- **G24 确定性**：同种子同输出（块划分、分数、展开）。
- 变异（各自须让至少一条守卫变红）：把短单元也切（短单元走块路径）→G21；单元阈值 off-by-one（k ≥ K_MAX 即算长）→G21；块阈值 off-by-one（允许 K_MAX+1）→G22；
  关掉 K_MAX 切块（长单元整条一块）→G22；关掉块展开（长单元只由首块代表）→G23。
