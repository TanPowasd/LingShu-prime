# VSA/HDC 记忆 · 理论核（阶段 1，写于任何读数之前）

日期：2026-10-18。目录 `TanPowasd/vsa/` 是全新探索，与 `agm/` 无代码依赖；评测时只读 import `agm/umb`、`agm/bench`、`agm/all`
的数据加载与指标函数（不改它们）。约束：零 LLM、零 API、零训练神经网络；确定性（所有随机向量由 `blake2b(种子|名字|块号)` 派生，
不用 Python `hash`，不用全局 RNG）。依赖：numpy、scipy（仅 `scipy.sparse` 做共现矩阵乘）。

## 1. 选定的 VSA 族：MAP-B（双极 Multiply-Add-Permute），D = 10000

| 原语 | 定义 | 代码锚点 |
|---|---|---|
| 原子向量 | `x ∈ {−1,+1}^D`，每维独立等概率；`vec(名字)` 由 blake2b 派生种子，按 1000 维一块生成（块可独立重算） | `hdc.py: Space.vec` |
| 绑定 ⊗ | 逐维乘 `a⊗b = a∘b`；双极下自逆：`a⊗a = 1`，故 解绑 = 绑定 | `hdc.py: bind / unbind` |
| 叠加 ⊕ | 整数逐维求和 `Σ x_j`（不截断，保容量）；需要回到双极时 `sign`，平票按固定种子的平票向量取号 | `hdc.py: bundle / sgn` |
| 置换 ρ | 循环移位 `ρ^n(x) = roll(x, n)`，用于编码顺序（第 n 位 = ρ^n） | `hdc.py: permute` |
| 相似度 | 余弦 `cos(a,b)`；随机原子对之间 `cos ~ N(0, 1/D)` | `hdc.py: cos` |
| 清理记忆 | 码本 `{名字: 原子}`，`cleanup(y) = argmax_名字 cos(y, 原子)`，同时返回最高分与次高分之差（边距）| `cleanup.py: Cleanup` |

**为什么选 MAP-B 而不是 BSC：** 二者代数等价（BSC 的 XOR ≅ 双极乘法），但 MAP 的整数叠加不需要每步多数表决，
叠加 k 项后再解绑的信号是确定的 1（见 §4），容量公式简单可检；BSC 每次叠加都要截断，信噪比按 `√(2/(πk))` 衰减。
两种叠加我们都实现并都写进守卫（整数叠加用于记忆痕迹，sign 叠加只用于理论对照）。

## 2. 记忆编码：一条记忆痕迹 = Σ 角色 ⊗ 填充

写入一条文本（一轮对话 / 一段 / 一个事件）时，规则抽取器（`memory.py: extract_roles`）给出若干 (角色, 填充, 规则号, 原文片段)。
角色集合固定为：`SPEAKER`（说话人）、`TIME`（时间）、`AGENT`（施事/主语人名）、`WITH`（同伴）、`ACTION`（动作/谓词）、
`PLACE`（地点）、`ENTITY`（其他实体，可多个）。痕迹：

```
T = Σ_{(r,f) 抽到} R_r ⊗ F_f   ⊕   R_BAG ⊗ Σ_{n} ρ^{n mod P}(I_{w_n}) (仅当打开顺序编码)   ⊕   R_BAG ⊗ Σ_w I_w
```

- **填充原子与角色无关**：`F_小王` 在 AGENT 与 WITH 中是同一个原子，角色只靠与 `R_r` 绑定来区分（否则角色向量就是多余的）。
  每个角色的清理码本 = 该角色下出现过的填充集合。
- 抽不到的角色**不写**（不放空占位），对应信息只留在词袋 `R_BAG ⊗ Σ I_w` 里。规则全部写死在 `memory.py` 的规则表里，
  每个抽取结果带规则号与原文片段，可回溯（白箱）。
- 一个角色可有多个填充（如多个 ENTITY）：同一角色下的多个填充直接叠加，解绑后清理得到的是并列候选，按余弦排序。
- 顺序：句内词序可选用置换编码（`ρ^n`）；事件流顺序由 `TIME` 角色 + 写入序号承担，不再叠进同一向量。

**查询**
1. 相似度检索 `search(q)`：问句词袋向量 vs 每条记忆的内容向量（§3 的语义向量加权和），余弦排序。
2. 解绑查询 `query(role=?, given={角色: 填充})`：
   (a) 由 `given` 构造探针 `P = Σ R_r ⊗ F_f`，与每条痕迹 `T_i` 求**点积**（不是余弦）：点积 = 命中 given 项数 × D + 噪声，与痕迹长度无关；
       余弦会偏向项数少的短痕迹（如闲聊句只含人名+星期），所以用点积。这一步本身就是一次清理：痕迹库即清理记忆。
   (b) 只在「点积 ≥ 最高点积 − D/2」的并列组（命中 given 项数相同）内，按点积降序依次解绑 `y = R_? ⊗ T_i`，对该角色码本清理；
   (c) 第一个所有目标角色边距 ≥ `MARGIN_MIN` 的痕迹给出答案；并列组内全部存疑则显式返回「存疑」，不静默给答案。
   (d) 外部可给候选顺序（如检索分数）代替 (a)，用于真实集（时间解绑）。

## 3. 语义来源：Random Indexing（为何不是神经网络）

每个词 w 有一个固定随机**索引向量** `I_w`（§1 的原子）。写入时对每个出现位置把窗口 ±W（W=2）内邻居的索引向量累加到 w 的
**上下文向量**：`C_w += Σ_{0<|j|≤W} I_{w_{n+j}}`。等价地 `C = A · I`，A 是写入时增量维护的稀疏共现计数矩阵
（`ri.py` 存 A，按需做稀疏×稠密乘；守卫验证二者逐位相等）。词的语义向量：

```
S_w = I_w + β · Ĉ_w,   Ĉ_w = C_w · √D / ‖C_w‖   （β 预注册为 0.5；C_w = 0 时 S_w = I_w）
```

两个从不共现、但上下文相同的词（如 car/automobile），其 C 向量由同一批邻居索引向量组成，余弦高；随机词对的余弦 ≈ 0。
**这不是神经网络**：没有可学习参数、没有梯度、没有损失函数、没有迭代优化；`C` 是计数的线性随机投影
（Johnson–Lindenstrauss：`cos(C_a, C_b) ≈ cos(A_a, A_b)`，误差 O(1/√D)），全过程是一次加法累计，可逐项回溯到哪次共现贡献了哪一维。
它是共现计数的随机降维，与 LSA/HAL 同族，不是 word2vec（后者有 SGD 训练的权重）。

文本内容向量：`V_i = Σ_w (1+ln tf_{i,w}) · idf_w · S_w`，`idf_w = ln(1 + N/df_w)`。β = 0 时 `V_i·V_j ≈ D · BoW 点积` + O(√D) 噪声，
即退化为随机投影的 TF-IDF 余弦；β > 0 时加入二阶共现（语义泛化）。查询向量同式；问句里不在库词表中的词跳过（它们只有随机 I，对任何文档都是噪声）。

## 4. 容量理论（叠加 k 项时的信噪比）

设痕迹 `T = Σ_{j=1}^k R_j ⊗ F_j`（整数叠加），解绑 `y = R_t ⊗ T = F_t + Σ_{j≠t} R_t R_j F_j`。

- 正确填充：`y·F_t = D + N_1`，`N_1` 是 (k−1)·D 个独立 ±1 之和，`Var = (k−1)D`。故 `E cos(y, F_t) = 1/√k`（因 ‖y‖² ≈ kD）。
- 干扰填充 G（独立原子）：`y·G` 均值 0，`Var = kD`。
- 单个干扰胜出概率 `p₁ = Q(√(D/(2k−1)))`；N 个候选的码本，错误率上界 `ε ≤ (N−1)·Q(√(D/(2k−1)))`。
- 由此**分块上限**：`K_MAX(D, N, ε) = ⌊(D / z² + 1) / 2⌋`，`z = Q⁻¹(ε/(N−1))`。D=10000、N=1000、ε=1e−3 → z≈4.75，K_MAX≈221。
  一条痕迹（或一个块）里叠加的绑定项数超过 K_MAX 时 `memory.py` **拒绝写入并报错**（不静默降级），调用方必须分块。
- sign 叠加（BSC/截断对照，k 为奇数）：`E[x_t · sign(Σ x_j)] = C(k−1, (k−1)/2) / 2^{k−1} ≈ √(2/(πk))`，信噪比低于整数叠加。
- 词袋项的数量也计入 k：一条 LoCoMo 轮约 10–40 个词项 + ≤7 个角色项，远低于 K_MAX；整段对话叠成一个向量（k≈10⁴）则必然失败——
  这就是为什么记忆是「痕迹库 + 清理」，而不是一个全局总和向量。
- 解绑探针 (a) 的检索：探针含 g 项、痕迹含 k 项，正确痕迹的点积期望 = g·D（每个 given 项各贡献 D），干扰痕迹（与 given 无共享填充）
  期望 0、方差 g·k·D；共享部分填充的痕迹（如同一人另一天）期望 = 共享项数·D。故 given 越多，区分越强；
  只共享 g−1 项的近邻与正确者之差恒为 D，`p₁ = Q(√(D/(2·g·k)))`。

## 5. 不变量（写成可检查断言，守卫 `test_vsa.py` 覆盖）

- **I1 绑定可逆**：`unbind(bind(a,b), a) == b` 逐位相等；`bind(a,b) == bind(b,a)`；`cos(bind(a,b), a)` ~ N(0,1/D)（|·| < 5/√D）。
- **I2 叠加容量**：k ∈ {1,3,9,27,81} 个随机绑定项整数叠加，解绑后对正确填充的平均余弦与 `1/√k` 相差 < 0.02；
  sign 叠加与 `C(k−1,(k−1)/2)/2^{k−1}` 相差 < 0.02（200 次平均）。
- **I3 解绑取回**：k ≤ K_MAX 时，码本 N=200 下每个角色解绑后 **argmax 100% 是正确填充**（误差界 ≈1e−6），且从不给出错误填充
  （只可能是正确填充或「存疑」）；存疑率 ≤ 5%（边距阈值 2σ 与正确余弦自身 ±σ 波动叠加所致，k=156 时理论约 0.2%/次）。
  超过 K_MAX 写入抛 `CapacityError`。注意 K_MAX 保证的是 argmax 错误率，不是存疑率：k 越接近 K_MAX，存疑越多（诚实代价）。
- **I4 RI 语义**：玩具语料中从不共现但上下文相同的词对，`cos(S_a, S_b)` > 随机词对最大值；`C = A·I` 与逐次累加逐位相等。
- **I5 确定性**：同种子同名字 → 同向量；写入顺序打乱后 RI 的 A、C 与内容向量逐位相同（写入序无关）；两次构建分数逐位相同。
- **I6 规则抽取可回溯**：中英文各一组定例，抽取结果（角色、填充、规则号）固定；每个结果的原文片段 ⊂ 原文。
- **I7 存疑而非静默**：清理边距（最高−次高余弦）< `MARGIN_MIN = 2/√D` 时返回 `("存疑", …)`。依据：角色缺席时解绑结果对码本全是噪声，
  N 个 N(0,σ²)（σ=1/√D）的最高两项间隙 ≈ Exp(均值 σ/√(2 ln N))，P(间隙 > 2σ) ≈ e^{−2√(2 ln N)} ≈ 1.5e−3（N=200）；
  角色在场且 k ≤ K_MAX 时边距 ≈ 1/√k − √(2 ln N)·σ ≥ 0.067 − 0.033 > 2σ。
  **修订记录（任何基准读数之前，守卫阶段）**：初版写 4/√D（「4σ」凭直觉），守卫 G3（k=156、N=200）出现正确填充被判存疑——
  与 §4 自身推导矛盾（1/√156 − 3.3σ ≈ 0.047，接近 0.04）。按上式改为 2σ，属理论修正而非调参。

每条守卫至少一个定点变异（`--mutate`：用 monkeypatch 把对应实现弄坏），变异后对应守卫必须变红。

## 6. 诚实边界

- 规则抽取是写死的浅层模式（人名=说话人表/首字母大写词/“和/跟/与/with”后接人名；地点=“在/去/到/at/in/to”后的片段；
  动作=闭集动词表；时间=日期/星期/相对时间正则）。真实对话里抽取覆盖率低、会抽错；抽不到只能退回词袋——此时 VSA 检索≈随机投影 TF-IDF，
  **不应期待它超过 BM25**。阶段 1 只测「代数是否成立」与「真实集上可用到什么程度」，不宣称提升。
- 合成基准由同一套模板生成、同一套规则抽取，抽取近乎完美是构造使然：它检验的是 **组合查询的代数**（主语/同伴区分、多条件合取），
  不是抽取鲁棒性。
- RI 只用本记忆实例写入过的文本（每段 LoCoMo 对话 / 每个 PerLTQA 角色 / hive 全库各自独立），语料小，二阶共现稀疏，语义泛化有限（推断）。
- 随机投影有 O(1/√D) 噪声：β=0 的 VSA 检索与精确 TF-IDF 余弦的名次在近平分处会翻转；这不是 bug，是 D 有限的代价。
- 时间解绑只能给出写入时规则落到 TIME 角色上的填充（会话日期或规则解析的相对日期）；金标若是「the week before X」这类相对表达，
  只有规则恰好产生同样表达时才算对；评测为描述性。

## 7. 阶段 2 增补（2026-10-18，写于阶段 2 任何读数之前；预注册见 `PREREG_v2.md`）

**7.1 分工：检索交给 te，VSA 只做候选上的结构化解绑。** 阶段 1 读数表明 VSA 相似度检索 ≈ BM25、显著不如 te（RESULTS_v1 §b），
故阶段 2 不再用 VSA 排序：候选 = UMB te 臂已缓存的逐题 top10（只读），VSA 只在这 10 条痕迹上解绑 TIME / SESSION。
候选外的轮**不得**参与作答（不静默回退全库）；这是一条可检查的边界（I10）。

**7.2 时间 = 两个角色。** 阶段 1 把「文中显式时间」与「会话日期」都写进 TIME，解绑时无法区分「这轮说了时间」与「这轮只是那天说的」。
阶段 2 把会话日期写进独立角色 `SESSION`，TIME 只放规则从文本解析出的显式时间（一轮至多一个，取文中最先出现者——同一角色叠加两个填充时
两者余弦都 ≈ 1/√k，边距 ≈ 噪声，必然存疑，见 §4/I7）。于是「这轮有没有显式时间」由清理边距直接回答：无 TIME 项时解绑结果对 TIME 码本全是噪声，
边距 < MARGIN_MIN ⇒ 存疑（I7 的同一推导）。作答 = 候选前 K 个里第一个 TIME 非存疑者，否则首候选的 SESSION（「显式时间优先」）。
存疑阈值在这里第一次承担真实决策：阈值关掉，无时间的轮会吐出码本里的随机日期（守卫 G13 变异）。

**7.3 时间规范化 v2。** 规则表见 PREREG_v2 §A（`memory.py: RE2_EN / RE2_ZH / _fill_en / _fill_zh`，规则号 `en-TM2-*`、`zh-TM2-*`）。
基准 = 写入时的会话日期 b；「last \<星期\>」= b 之前最近的该星期（严格早于 b），与金标「The Friday before D」换算成同一 DATE。
问句粒度（which/what year、month，哪年、几月）在作答后粗化。规范形是有限字符串，判对 = 规范形相等；J2 只做**等价**换算，不做跨粒度宽松。

**7.4 指代与省略（合成 v2）。** 一步白箱规则：无 AGENT 且句首是代词 / 省略主语 ⇒ AGENT := 紧邻上一句 AGENT，句中无 TIME 则继承上一句 TIME。
不做多句回溯、不做性别一致检查（推断：真实对话需要更强的消解，本规则只对生成器的「引导句 + 代词句」结构成立）。

**7.5 多跳 = 多次解绑的集合运算。** T4「X 和 Y 都去过哪」= 两组探针（AGENT=Z、WITH=Z，点积 ≥ D/2 的痕迹）各自解绑 PLACE 后求交；
T5 链式 = 第一跳解出 Y 作为第二跳探针的 given。每一跳都是 §2 的同一查询，误差可加：两跳精确率 ≤ 单跳精确率之积（推断，独立近似）。

**7.6 新不变量（守卫 G10–G15）**
- **I8 规则定例**：v2 时间规则表每行至少一例、结果固定；片段 ⊂ 原文。
- **I9 粒度**：问句要年 / 月时，答案粗化到该粒度；无粒度词时不变。
- **I10 te 候选限制**：作答所用的轮 ∈ te top10（经说话人过滤）。
- **I11 存疑 + SESSION 回退**：无显式时间的轮 TIME 解绑必须存疑；此时答案来自 SESSION，来源字段如实标注。
- **I12 合成 v2**：代词/省略句经 coref 后单跳、多跳交集、链式在规则覆盖的模板类上精确。
- J2 判定定例（G15）：金标等价换算固定。

**7.7 诚实边界（阶段 2）**
- v2 时间规则参考了阶段 1 在 LoCoMo dev 上的 oracle 失败分析，读数在同一 dev 上 ⇒ LoCoMo 读数是乐观的开发集读数；PerLTQA dev 未参与规则设计，作为旁证。
- te top10 不含金标轮的题，VSA 无论如何都答不对：端到端上界 = te10 含金标轮比例 × oracle。
- 合成 v2 的 C4（规则外改写）是刻意保留的抽取失败：VSA 的精确性完全建立在抽取之上，抽不到就答不出（以存疑或错答体现）。
