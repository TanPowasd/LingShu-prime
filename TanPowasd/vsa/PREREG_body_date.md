## 1. BD 规格（实现必须逐条照此；守卫 G29+ 锁定）
1. **作用范围**：只对长单元——该单元 L1 写入时的整单元载荷 `(memory.tokens(原文), 单元角色)` 的 `seg.n_items` > K_MAX（与 `seg.is_long` 同口径）。短单元不产生子痕迹。
2. **句流**：`seg.split_sents(原文)`；纯编号碎片（不含汉字、不含拉丁字母的句，如「12.」）并入下一句（以一个空格连接），使「12. 3月6日：…」成为一句。
3. **句内日期**：每句至多一个日期 = 时间函数 `time_fn(句)` 的结果（`[]` 或一个 `TIME` 项，即该句文中最先出现的可解析时间，规则同 `extract_time_v2`）。
   各口径的 `time_fn`：crossproj / LoCoMo 口径 = `extract_time_v2(句, 会话日期, lang=单元语言)`；PerLTQA 口径 = `seg_real.zh_time` 的 TIME 项（与 L1 的句角色同一函数）。
   一句内第二个及以后的日期不入任何痕迹（诚实边界，沿用 THEORY §7.2「一条痕迹一个 TIME」）。
4. **启用条件**：该长单元各句日期的**不同填充**数 ≥ 2 才产生子痕迹；否则（0 或 1 个不同日期）不产生，单元解绑逐位 ≡ L1。
5. **锚点规则 B-iii**：按句序扫描，维护当前锚点 A（初始为空）：
   - 句有日期 f，且（A 为空 **或** 该日期是**句首日期**）⇒ A := f，本句 TIME = f（开新锚点）；
   - 句有日期 f，但 A 非空且 f 是**句中日期** ⇒ 本句 TIME = f，A 不变（句中日期只管本句，下一句回到 A）；
   - 句无日期 ⇒ 本句 TIME = A；A 为空（单元首个日期之前的句）⇒ 本句 TIME = 单元首个日期（规则 1「初始锚点 = 单元首个日期」）。
   - **句首日期**的判定：去掉句首可选前缀「说话人: 」（`^[^\s:：]{1,16}: `）与可选编号（`^\(?\d{1,3}[.、．)）]\s*`）后，该句日期片段的起点 = 0。
6. **子痕迹**：**每句一条**子痕迹（实现细节，读数前定：比「锚点段一块」更细，使问句余弦对准单句而不被大块稀释；推断：这对 (b) 表头题更安全），
   项 = 一个 `ROLE:TIME ⊗ F:本句 TIME` + 本句词袋 `ROLE:BAG ⊗ I_w`（同 `Memory.trace` 编码）。单句项数 > K_MAX ⇒ 按词序切片，每片都带同一个 TIME（每条子痕迹恰一个 TIME 且 ≤ K_MAX）。
   子痕迹**不进**检索索引（不写 `texts / toks / roles / codebooks / ri`）；清理用独立码本 = L1 的 TIME 码本名 ∪ 子痕迹填充（L1 码本不变）。
7. **单元内选择（只用于 TIME）**：问句内容向量与各子痕迹内容向量（同 `Memory.vectors` 的 idf + RI 投影、β=0.5）的余弦降序（稳定，平局按句序），
   依次解绑 TIME，取第一个非存疑；全部存疑 ⇒ 存疑（来源 `bd`）。最大余弦 ≤ 0 ⇒ **显式回退** `Memory.decode_unit`（来源 `fallback`，计数上报，不静默）。
   无子痕迹的单元 ⇒ `decode_unit`（来源 `l1`）。
8. **作答**：新增 `real_v2.answer_time_q(m, cand, k, 问句)`：同 `answer_time`（候选前 k 个里第一个 TIME 非存疑；否则候选第一个的 SESSION；否则存疑），
   只把单元 TIME 解绑换成 §1.7。`answer_time` 不动。
9. **开关**：`Memory(body_date=False)` 默认关；`write(..., body_date=None, time_fn=None)` 可逐次覆盖。Memory 默认是否改为开，由 §5 判定决定。

## 7. 守卫（续编 G29+，实现提交时一并提交）
- 每子痕迹恰一个 TIME 项且 ≤ K_MAX；短单元与无多日期长单元：BD 与 L1 解绑 / 状态逐位相同；
- 检索索引逐位相同（texts / toks / roles / codebooks / RI / 分数 / 排序）；
- B-iii 定例：表头句中日期 = 初始锚点；句中日期只管本句、下一句回到锚点；句首日期开新锚点、后文继承；编号前缀不影响句首判定；
- 选择定例：问句贴近句中日期句 ⇒ 该日期；贴近无日期条目 ⇒ 其锚点；余弦 ≤ 0 ⇒ 来源 `fallback`；确定性；
- 定点变异全红（至少：句中日期当锚点、选择忽略问句、子痕迹写进检索库、范围泄漏到短单元、子痕迹并多个 TIME、去掉启用条件）；旧 G1–G28 全绿、旧 38 条变异全红。
