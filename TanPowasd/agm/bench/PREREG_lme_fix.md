# 预注册：v3 两处掉分的修复候选（2026-10-14 21:20，跑任何读数之前写）

起因：lme_diag.py 归因（2222685）——v3 在 LongMemEval-S 落后整词 BM25，来自 BM25+ δ 下界（−.024）与 AGM 扩散（−.028，集中 multi-session）。
注意：归因本身用了全部 479 题，所以下面的「test」不是完全干净的留出，只保证选型不碰 test（如实声明）。

## 候选（只这两个旋钮，其余 v3 参数不动）
- δ ∈ {1（v3 原值）, 0}
- 会话限额 cap ∈ {无, 1, 2, 3}：AGM 扩散后，非种子块按激活序计数，同一会话超过 cap 个的退回按块打分排在扩散段之后（种子不计、不受限）。
  会话由调用方给（LongMemEval 用 haystack 会话，LoCoMo 用 dia_id 的 D 号）；不给会话时与 v3 逐位相同。

## 划分与判定
- LongMemEval-S：dev = md5(question_id)%3==0，test = 其余；只算有 gold 的题。
- 选型：dev r@10 最高的组合；与次优差 <.005 时取改动更少者（δ=1 优先，其次 cap 无 > 3 > 2 > 1）。
- test 只跑一次，报选中组合 vs v3、vs 整词 BM25 的 r@10 与配对符号检验。
- 非退步复核：选中组合在 LoCoMo dev（231）与 test（1300）上 vs v3 的 r@10；判定「不退步」= 不出现 v3 显著更好（符号检验 p<.05）。
- 只要 test 上 vs v3 不显著（p≥.05）就如实写「未证实」，不再追加旋钮。
