# Lex 漏检取证（dev，只读诊断，diag_lex.py）
金标轮：LME 304、LoCoMo 308。漏检 = 管线名次 ≥ 10。实词 = df/N ≤ .10 的问句词（说话人名等高频词被排除）。

| | LME | LoCoMo |
|---|---|---|
| 漏检金标轮 | 91（30%） | 133（43%） |
| 漏检中实词零重叠 | 26 | **88** |
| 实词覆盖中位数 命中 / 漏检 | .43 / .14 | .40 / .00 |
| 漏检单独名次 11–30 / 31–100 / >100 | 52 / 25 / 14 | 33 / 36 / 64 |
| 漏检落在多金标题里的比例 | 89% | 65% |
| 题目 全中 / 部分中 / 全漏 | 108 / 32 / 22 | 142 / 21 / 68 |
| AGM 挤出 / 救回 | 8 / 2 | 5 / 28 |
| 漏检最多的题型 | multi-session 50/114，temporal 25/87，preference 11/18 | cat1 多跳/列举 65/87 |

样例（LoCoMo，零重叠漏检）：问 games，证据说 Fortnite / The Witcher 3；问 cities，证据说 Paris；问 tricks，证据说 taught my dogs to balance；问 meet at，证据只有 “Yeah! Let's do it.”（意思在上一轮）。

推断的四类原因：① 类别↔实例鸿沟（问类别，证据说具体实例）；② 列举题需要多条证据，只找到一条；③ 证据轮本身没内容、意思在相邻轮（AGM 在 LoCoMo 救回 28 正是这一类）；④ 时间题的证据不含问句里的时间词。
