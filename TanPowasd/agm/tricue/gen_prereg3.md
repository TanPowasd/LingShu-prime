## 主指标
- 流式：窗口外覆盖（逐文件符号检验对 v1.1 与对最强单路）
- 续接卡：hit@10；LoCoMo：证据轮 @10；LongMemEval：会话 @5

## 判定（选定 v3 主臂后在此补写臂名，然后冻结）
v3 主臂须同时满足：
1. 流式 test 窗口外 ≥ v1.1，逐文件不输多于 2/10；
2. 四项 test 主指标都不低于最强单路基线（chunk3、turn3、turn_okapi、agm3）减 1 个百分点；
3. 至少三项高于 v2（tc2）读数。

## AGM 泛化（用户 2026-10-11 追加）
同时报告：agm1、agm3（AGM 单路）、v11_noagm、tc3_noagm 在四项 test 上的读数。AGM 视为“泛化有效”的条件：在全部四项 test 上，去掉 AGM 的读数都不高于带 AGM 的读数。
