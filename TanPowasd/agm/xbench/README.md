# xbench — 外部公开检索集扩测（零模型、零 key）

四臂：BM25（Okapi k1=.9 b=.4）、Lex（BM25+ δ1 + 拉丁轻词干 + RM3）、zh（中文打分：去虚词二元组、中文问句不做 RM3）、RA-AGM_zh（zh + 同文档切块间角色感知扩散）。
指标 nDCG@10 / R@10 / R@100 / MRR@10；胜负为逐题 nDCG@10 配对符号检验。ArguAna 按 BEIR 惯例去掉与问句同号的文档。

数据（不入库）：`python fetch.py` → BEIR 英文集与 C-MTEB 中文集（转成 BEIR 格式）。
复现：`python bench_ir.py <数据目录> [--split dev] [--maxchars N] [--shard i/n] --out x.json`，`python agg_ir.py <结果目录> --out agg`。

注意：
- **缩库**：Cmedqa（800 万字，保留全部金标文档）、Covid、Du（1200 万字）在 7 GB 主机上全库会 OOM，读数只能做同库臂间比较，不能和 C-MTEB 公开榜单比。
- **部分题**：Cmedqa 只完成 2/4 片（2000/3999 题）、Du 2000 题。其余集为全部题。
- 每篇文档是独立会话，没有跨文档的边，所以 RA-AGM_zh 在这些集上与 zh 逐位相同——这里测的是中文打分本身，不是扩散。
- 英文集上 zh/RA-AGM_zh 与 Lex 逐位相同（中文路径对纯英文不触发），符合设计。
