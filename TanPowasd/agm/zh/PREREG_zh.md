# 预注册：RA-AGM_zh + 逻辑链条（2026-10-15，test 读数前提交）

用户：「来对中文做优化，raagm_zh 算法来一个」「再加上逻辑链条算法」。基线 = Lex + RA-AGM（中文上与纯 Lex 逐题相同）。

## 算法
- `zh.py` RA-AGM_zh：问句里去掉两个字都在 QSTOP（中文疑问/虚字集合）的二元组（「什么」「哪些」「是否」…），去完为空则不去。
  QSTOP 只含汉字 ⇒ 英文问句逐位不变，不需要语言闸门。其余与 Lex + RA-AGM 相同。
- `chain.py` 逻辑链条：每段同时写入 RA-AGM_zh 与 agm/reason 的编年版本链；题面被 Reason 认出（已登记主体 + 的 + 已登记属性）时，
  排头 = 编年链选中的那一版所在段（变更题 = 整条链各版的段，按序号），后接 RA-AGM_zh 排序；认不出时与 RA-AGM_zh 逐位相同。
  这是一条检索路径（按显式条件决定排头），不是多路投票/融合。
