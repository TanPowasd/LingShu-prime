## 句框（2026-10-13）
`Reason(frames=[("说到⟨A⟩，⟨S⟩ 这回定为", "set"), …])`：自主学习归纳出的整句骨架排在原动词表之后匹配；多个说法同时命中时取属性最短的切法。官方语料读数不变（1.000）；守卫 R13/R14 + 变异 M7/M8。

## 边界（务必一起读）
- 动词表是看着官方语料的句式写的；新种子只换内容不换句式，所以 1.000 只说明「句式在表内时，版本推理本身不出错」，等于结构化对照上限（chronicle/bench_chain.py 642/642）。
- 表外说法一律抽不到：句式扰动下掉到 .402。这正是「自主学习」模块（../learn）要补的缺口。
- 题面解析率 .986：其余 1.4% 是「不存在」题，主体本就不在记忆里，按 absent 作答且判对。
