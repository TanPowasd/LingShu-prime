# 自主学习 Learn（记忆四能力套件 · 自主学习）

零模型、零网络、零判官。从已经懂的句子里自举学会新说法：已知槽「主体 的 属性」+ 已知取值池 ⇒ 未知连接词是一种「改成」；在 ≥2 个不同槽上出现且取值落池才晋升，晋升后整库重放巩固，迭代到不动点。`learn_until` 前学后测，不偷看未来。

## 复跑
```bash
python -X utf8 bench_learn.py <hive-memory-bench>                 # 混合扰动 p=.5，3 个扰动种子，~7s
python -X utf8 bench_learn.py <hive-memory-bench> --p 1.0         # 全部换成表外说法
python -X utf8 bench_learn.py <hive-memory-bench> --corpus-seed 7 # 生成器新种子语料（保留集）
python -X utf8 test_learn.py            # 守卫 9 条
python -X utf8 test_learn.py --mutate   # 定点变异 6 条
```

## 边界
- 扰动替换词表是我写的，学习器和扰动都出自同一侧；真实口语的说法更散，未测。
- 只学「改成」类与隐含属性类；撤销、两说并存、裁定类的新说法不学。
- 取值校验在本语料上偏保守（.986 vs 不校验 .997），本语料没有能骗过槽数门的噪声，所以它的防护作用只在守卫 L4 里被证明，没在基准里体现出收益。默认值未按本读数调整。
- 学习要求句中带空格分隔值，或值本身已在取值池里（逐位试切）。
