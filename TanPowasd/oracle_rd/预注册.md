## 3. 臂（只替换被测那一级）
reader 系统提示词 `READER_SYS`、用户模板 `READER_USER`、judge `JUDGE_SYS` 由 `run.py` 从仓内 `md_cg.bench_e2e_qa` / `md_cg.bench_e2e_locomo_qa` 直接 import；temperature=0；reader max_tokens 300、judge 200（与 bench 同）；三臂同模型 `cline-pass/deepseek-v4.1-flash`。唯一变量是「候选记忆」段：

| 臂 | 候选记忆 |
|---|---|
| C 闭卷 | 「（无）」 |
| S 系统交付 = D 原文交付 | 系统真实 top-10 原文，系统顺序，`【i】` 编号以空行连接（bench retrieval 臂同形） |
| R 完美检索 | 该题全部 gold 证据原文，按 (session, turn) 时序，非 gold 零注入 |

**S 与 D 构造上是同一输入（已取证，不是省略）**：
1. bench `bench_e2e_locomo_qa.py` 的 retrieval 臂本身就是「top-10 节点原文全文直交」，无渲染模板、无预算裁剪——它已满足 §5.1 D-oracle 定义。
2. 生产查询交付面 `MdCGOS.recall` 装包（`DEFAULT_BUDGET=1200`、`DEFAULT_MAX_ITEM_TOKENS=250`）：对这 100 题的 top-10 机械核算，**0/100 题会触发截断或跳过**（`prep.py` 的 `recall_pack_would_cut`）。
3. 客户端 `formatTimelineDecayed`（分级递减前缀截断）喂的是 `graph.timeline` 最近记忆，**与查询无关**，不在问答交付路径上。
故 Δ_doc ≡ Δ_sys，D 臂不单独花调用；省下的 100 次 reader 用于闭卷臂（规格要求"预算允许则加"）。存疑：MCP `cg(op=read)` 把装包渲染给宿主的文本格式未逐字取证，但不改变"不截断"这一结论。

## 4. 读数
- 各臂准确率（correct/100）、拒答数（judge=refused）、错误行数。
- Δ_sys = Δ_doc = S − C；Δ_R = R − C；另报 R − S（检索净损失）。
- 区间：题目级配对差；以 conversation 为簇的自助法（簇内整簇重抽，B=10000，种子 20261014），95% 百分位区间。
- 辅助：按 hit@10 命中/未命中拆 S；按 category 拆三臂。

## 5. 判据（先于读数写定）
**档位**：某差值记「高」⇔ 点估计 ≥ 3pp 且 95% 区间下界 > 0；记「≈0」⇔ 区间含 0 或 |点估计| < 3pp；其余记「低」（正但不显著，或为负）。3pp 取自规格 §5.4 的改写噪声量级。

**四形态**（规格 §5.3）：一 = 三者≈0（瓶颈在写入/表示）；二 = sys 低、doc 高、R 低（交付层 D）；三 = sys 低、doc 低、R 高（检索层 R）；四 = sys 低、doc 高、R 高（R+D 叠加）。本实验 doc≡sys，形态二/四在构造上不可达，D 维按规格 §5.3 判读纪律记「**不可观察→本口径无交付抽象层，记不适用**」。

**能红条件**（规格 §5.4）：
1. Δ_doc − Δ_sys ≤ 3pp ⇒ 推翻"瓶颈在 D"。本口径下 ≡ 0，**预先声明为构造性成立**（即本口径下 D 不是瓶颈）；它只对 bench/recall 查询路径成立，不外推到 autoRecall 时间线块。
2. Δ_R > 0 而 Δ_doc ≈ 0 ⇒ 检索把错节点交给交付层，交付层无辜。
3. 某臂准确率上升同时拒答数同步上升 ⇒ 疑为格式/提示词效应，须回查。

## 6. 调用预算与纪律
- 3 臂 × 100 题 reader = 300；judge ≤ 300（内容寻址缓存：同题同答案复用判分）。硬上限 650 次 HTTP（含失败重试，单次最多 3 试）；达上限即停，不补跑。
- 先以前 2 题冒烟（计入总数、缓存复用），再全量。
- 凭据不读、不落盘：请求不带 Authorization，由运行环境按主机注入。

## 7. 诚实边界（先写定）
- 规格 §5.5/§7.1 阶段 0「《秤》校准零号试验」**未做**；本次读数的归因效力以该门未过为前提，结论只能是"本口径下的方向性读数"。
- 单 reader（deepseek-v4.1-flash），未做生成器交换；n=100、10 簇，区间会宽。
- 不做 D-oracle 的独立调用（理由见 §3）；未做原文全文臂（full_context）。
