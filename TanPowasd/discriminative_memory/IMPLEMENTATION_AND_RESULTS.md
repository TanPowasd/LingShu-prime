# 通用判别记忆：实现与离线测试

已实现可持久化的通用结构化核心，以及通用原文冷检索。核心不包含地点、人名、某篇小说或某段文字的专用规则。
实体、属性、角色和条件由输入 schema 定义；值支持 JSON 标量、列表与对象。事实解释和问题绑定由调用方确认，
不是本原型从任意自然语言自动推断的结果。全部测试与基准均未使用 key、模型或外部网络。

核心文件 `discriminative_memory.py`；可运行示例 `demo_discriminative.py`；基准 `bench_discriminative.py`；
验证 `verify_discriminative.py`。原始实验结果保存在 `results/original-20261010/`；本目录为实验实现，仓库 AGM/RRF3 主实现继续独立维护。

## 已实现的通用机制

- 不可覆盖的原文与解释记录：SQLite 持久化，原始记录和解释/控制行禁止 UPDATE、DELETE。
- 通用事实槽：任意 entity、facet、role、JSON conditions；不依赖具体实体名称或业务字段字典。
- 双时间与版本：实际状态、计划、未知解释分开；支持迟到历史、部分字段纠正、撤回/恢复和跨属性重新分类。
- 有来源的条件依赖：显式等值条件和槽内事件谱系绑定；无法证明的依赖与循环返回 defer。
- 冻结查询证据：当前状态、历史记录和计划模式；可跨多个实体/属性提出一组取证要求。
- 证据包：修订链、决定状态的撤回限定、依赖前提及引用身份共同组成原子包。相关冲突必须包含各值的依据。
- 预算选择：按新增要求覆盖/新增上下文成本选包，尝试单包替换与冗余消除。未完整满足的字段不泄漏未交付的值。
- 重复处理：只有显式同事件 provenance_group 且完整结构一致时共享解释。原文仍保存，其他同文、同值事件保留独立谱系。
- 依赖失效与有界缓存：按槽和明确引用的来源身份失效；缓存默认最多 256 个查询视图，淘汰缓存不会删除经历。
- 原文回退：任意文本可以保持 pending，通过通用二元组 BM25 查询原文；返回 evidence_only，不凭文字命中生成确认事实。

状态时间底层复用此前已验证的 `temporal_facts.py`（从此前 guarded-agm 实验按字节复制，归档保留原哈希）。新实现的部分包括通用 schema、
解释/原文分离、证据依赖编译、谱系与引用保护、压缩索引、预算规划、反馈重分类和缓存。
“泛用”在本轮指 schema 与实体名称无关的结构化引擎，不能等同于已具备通用自然语言理解。

## Python 接口

```python
from discriminative_memory import Memory, Slot, Need, Query, Dependency

m = Memory('memory.sqlite')
s = Slot.of('object_17', 'setting', role='runtime', conditions={'profile': 'P'})
m.append(
    'source_1', '{"setting":{"enabled":true,"options":[1,2]}}',
    assertions={s: {'enabled': True, 'options': [1, 2]}},
    effective_at=1, recorded_at=2,
)
answer = m.query(Query((Need('setting', s),), at=3, known_at=3), budget=1024)

# 未解释的原文不需要业务字段，也不会自动变成事实。
m.append_raw('raw_2', '任意来源原文', recorded_at=4)
hits = m.search_raw('来源', budget=512)
m.close()
```

`append` 接受调用方确认的结构，`correct` 修订指定字段，`set_enabled` 控制声明有效性，
`reclassify` 原子地撤回旧解释并登记新的实体/属性/角色绑定，`prepare` 返回共同证据规划问题。
角色与条件为精确分区；依赖目前是显式等值合取，尚未实现任意逻辑表达式或自动绑定。
收到时间必须按登记顺序非递减；事件生效时间可以早于收到时间。值可以是任意 JSON 数据，时钟需要显式数值。

## 随机 schema 预算测试

参数在检索前保存于 `parameters.json`，实现和依赖 SHA256 固定于 `results/original-20261010/readings.json`，没有根据成绩调参。
150 个新生成任务，每个包含 4～7 个要求与不同组合的共同依据。实体/字段标识随机，值混合数字、布尔、字符串、列表和对象。
五种原文格式为英文包裹、中文包裹、JSON、键值行和长描述。每种 30 个任务，构造时无需领域专用解释规则。
这不是五个真实领域的自然语言泛化验证，而是对不同表示形式和未知命名的结构化测试。

全部方法共享同一组确认结构、问题要求、来源、完整证据包和冲突政策。问题要求没有包含预先给定的目标答案。
预算为 Unicode 字符数，包含原文、来源头、修订/依赖等元数据；各方法使用相同粒度。
基准比较选择阶段，不把事实抽取或问题绑定的成功作为新选择器的优势。

指标为“加权证据要求覆盖率”：一个要求只有在整套有效依据已交付时才得分。它不是任意文本的语义召回率。

| 选择方法 | 512 字符 | 1024 字符 | 2048 字符 |
|---|---:|---:|---:|
| 判别记忆 | 62.1% | 91.4% | 100.0% |
| 判别记忆-无替换 | 61.1% | 90.2% | 99.9% |
| SQL直接取证 | 42.7% | 75.4% | 97.7% |
| 最短证据包 | 34.7% | 66.6% | 96.5% |
| BM25证据包 | 55.8% | 85.4% | 99.7% |
| AGM证据包 | 50.8% | 82.2% | 99.4% |
| RRF三路证据包 | 52.2% | 84.1% | 99.1% |

| 方法 | 1024 字符全要求满足 | 平均交付字符 | 选择阶段中位耗时 |
|---|---:|---:|---:|
| 判别记忆 | 85/150 | 757.9 | 1.24 ms |
| 判别记忆-无替换 | 81/150 | 745.0 | 0.50 ms |
| SQL直接取证 | 39/150 | 782.1 | 0.18 ms |
| 最短证据包 | 19/150 | 762.0 | 0.93 ms |

1024 字符下，相对 BM25 证据包为 51 胜、8 负、
91 平；相对 AGM 证据包为 57 胜、
6 负、87 平。只作本组合成分布中的描述。

SQL 直接取证按问题字段顺序与最新支持来源装包，不代表数据库能做到的最优策略；
最短包忽略覆盖数量，BM25/AGM 根据共同来源排序证据包，RRF 使用近因、BM25、AGM 三路排序。
这些是同条件选择基线，AGM/RRF 的包装方式与官方端到端记忆实现不同，不能把表中的差值当作正式基准胜负。
单值状态查询中，正确的双时间 SQL 就已经足够，本轮没有声称状态正确率是新规划器带来的收益。

39 个小实例做穷举上界比较，38/39 个实例的覆盖与上界一致。
剩余实例 40 在 1024 字符下，当前启发式为
50.0%，穷举为 75.0%。
因此单包替换不是最优性保证，复杂依赖或共享依据仍可能需要组合搜索。

## 泛用性、时间与重复检查

- 60 次 schema 重命名检查：实体、属性、角色和条件值换成另一组未见标识，选中的来源、覆盖与成本保持一致。
- 150 次重复记录检查：每个任务增加 8 条已确认同事件副本，结果不变。压缩的是派生解释索引，原文仍保留。
- 800 次独立时间 oracle 检查，800/800 通过：
  24 个随机实体、72 个不同槽、576 个状态声明经历、
  901 次登记/修订/计划/控制操作。状态分布为 {"known": 515, "unknown": 281, "conflict": 4}。
  给定结构的状态语义正确，不证明文本抽取正确。
- 读取不写入事实，不因重复查询提高真实性。缓存淘汰后仍能从不可变日志恢复答案。
- 未来或私有的引用身份不能为旧快照补证；未知引用后续出现时只失效依赖它的查询视图。
- 一条依赖若绑定到某条来源的槽内谱系，实际引用的身份记录也必须随包交付；修订/转载身份都有时间与权限检查。

本轮新测试 48 项；连同前面实验合计 **177 项通过**，
失败与错误均为 0。这是原始实验工作区的历史汇总；本目录附带本算法的 48 项测试，发布验证只运行这 48 项。
发布验证另外重新构建 12 个预算上下文，检查来源、完整覆盖和元数据成本，并核对归档原始文件及发布文件哈希。
时间查询中位约 0.37 ms；预算表的时间只含已编译证据问题上的规划与渲染。
这些小规模测量没有验证十万次变更/百万条自然语言经历的性能。

读取真实 hive corpus 的 303 个原文块，执行主轮 92 题和干预轮 92 题的回退原文查询，共 184 次。
2417 条交付原文逐字核对，预算违反 0，读时事实写入 0，自动推断的确认断言 0。
没有由公开答案键生成事实槽、问题要求或证据包，没有为这段小说写专用抽取器。
本项是原文接口与回源/预算验证，不能作为新算法的 hive 语义成绩；没有生成模型、判官或主轮通过率读数。

## 当前边界

当前可用的是通用结构化引擎与原文回退入口。自然语言事实抽取、指代解析、问题框架生成及自动反例学习尚未实现。
`reclassify` 接受明确反馈，能够改解释及失效相关视图，但没有从反馈学习通用文本分类器。
压缩只在显式同事件且完整结构一致时进行，尚未实现开放问题族上的语义等价压缩。
原文以整条 source 为交付单位，历史要求原子交付完整时间线，尚未实现自动 span 选择、流式分页和动态预算扩展。
候选证明展开最多 256；必须冲突包搜索有工作量上限，截断标记在结果中保留，不能把未找到计划当作不存在任何可行计划的证明。
来源定位与证据关系可检查，结构是否真正蕴含原文仍依赖确认方；没有验证下游模型是否忽略缺证标记或误用历史原文。
SQLite 数据持久化、作用域和可搜索性检查不等同于一个已经部署的多用户权限服务。

这些边界都没有通过特定文本的规则绕过。下一阶段应加入独立可测的通用解释器，分别报告解释错误与规划错误，
使用与这组合成 schema 不同的现实输入验证。涉及外部模型的完整评测继续遵守用户的事先授权要求。
