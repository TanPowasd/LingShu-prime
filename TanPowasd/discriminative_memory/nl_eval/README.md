# 自然语言解释器（零模型）与离线测评

`../nl_interpret.py`：把中英文句子解释成候选操作，再通过公开 `Memory` 接口写入；原文始终保留。不调用模型、不联网、无领域词表。

| 能力 | 做法 |
|---|---|
| 陈述 | `X的Y是/为/改为…Z`、`把/将X的Y改成Z`、`the Y of X is Z`、`X's Y is Z`、`set the Y of X to Z` |
| 计划 / 不确定 / 否定 | 话语标记（计划、打算、will…/可能、maybe…/不是、is not…）；计划写 plan，不确定只留原文，否定仅在当前值正是被否定值时置为未知 |
| 更正 / 撤回 | 更正、其实、actually… → `correct` 最新修订；撤回、disregard、scratch that… → `set_enabled(False)` 上一条 |
| 指代 | 它的/its… 绑定到上一个话题实体 |
| 时间 | `t=5`、ISO 与中文日期、昨天/今天/明天；日期若出现在值里就当值不当时间；无时间用收到时间，带「以前/曾经」又无时间则不写 |
| 条件 | `在…模式/环境下`、`in … mode` → conditions |
| 结构化 | JSON 与 `槽键 = 值` 行（本库的槽键编码） |
| 问题绑定 | `X的Y是多少/什么`、`what is the Y of X`、`what's X's Y`；历史/计划/时刻；实体和属性按字二元组 Jaccard 模糊对齐；绑不上就退回 `search_raw` 原文 |

## 读数（`python -B -X utf8 nl_eval/eval_nl.py --output nl_eval/results`）

**留出集**（22 个案例，解释器写之前写好并记哈希 `3de04c68…`，之后未改）：

| | 首次运行（冻结于 `first_heldout_run/`） | 修复后 |
|---|---:|---:|
| 声明精确率 | 29/29 = 1.000 | 30/30 = 1.000 |
| 声明召回率 | 29/32 = 0.906 | 30/32 = 0.938 |
| 问题答对 | 22/25 | 23/25 |

修复后那一项是看了留出集失败才改的（日期在值里被当成时间），属于事后修复，主读数以首次运行为准。
剩下两处失败都是解释错误：「后来她说她更喜欢英文」（无系动词的转述）、「will move its standup to 10am」（谓语里的物主代词）。绑定错误 0，记忆/选择错误 0。

**开发集**（8 个案例，边写边用）：声明 15/15，问题 11/11。只说明实现自洽，不作泛化证据。

**合成 schema 原文**（150 个任务的五种原文格式）：声明 3511/3511 全部还原，误报 0。

| 预算 | 确认结构 | 确认结构但用收到时间 | 解释器 |
|---:|---:|---:|---:|
| 512 | 0.621 | 0.411 | 0.411 |
| 1024 | 0.914 | 0.791 | 0.791 |
| 2048 | 1.000 | 0.982 | 0.982 |

解释器与「确认结构＋收到时间」完全相同，所以差距全来自原文里没有的生效时间与依赖，不是抽取错误。

## 边界
- 规则是表层句法，留出集只有 22 例且是我写的，不能代表真实对话；Hive 原文没有金标，未测。
- 不处理：无系动词的转述、跨句省略主语、谓语内物主代词、多实体并列、数量单位换算。
- 同名属性不同条件时，无条件问题优先取无条件槽。
- 测试：`python -B -X utf8 nl_eval/test_nl_interpret.py`（10 项）。放在包外，原发布验证的 48 项不受影响。

## Hive 语料实测（`python -B -X utf8 nl_eval/hive_nl_bench.py <hive-memory-bench> --json nl_eval/results/hive_nl_readings.json`）

零模型、零 key，检索面，同 `agm/bench/hive_retrieval_full.py` 的切块、预算与计分（primary 证据句完整落入上下文）。

- 303 块小说原文 → 92 条候选（state 68、uncertain 11、negate 10、plan 3），62 块写入了声明。
- 人工核对随机 40 条候选：严格可用 1 条（「巨子的理论是存在漏洞的」），宽松算 4 条，精确率约 2.5%–10%。主要错误：疑问句当陈述（「X的Y是什么」）、动词短语当实体（「获取风」「想要」）、比喻与转述、「或许」未识别为不确定。
- 问题绑定 0/92：主轮题都是主题/叙事题（「自由在故事中被呈现为两种对立形态…」），不是「X的Y」型事实问句。
- 因此「判别+BM25」与 BM25、「判别+RRF」与 RRF(BM25,AGM) 逐题完全相同：

| 预算 | BM25 | RRF(BM25,AGM) | 判别+BM25 | 判别+RRF |
|---:|---:|---:|---:|---:|
| 2000 | 0.267 | 0.290 | 0.267 | 0.290 |
| 4000 | 0.383 | 0.392 | 0.383 | 0.392 |
| 8000 | 0.521 | 0.530 | 0.521 | 0.530 |

结论：表层句法解释器在留出的事实型句子上可用，在叙事小说和主题问题上不起作用；Hive 上判别记忆目前只能退回原文检索，没有新增成绩。
