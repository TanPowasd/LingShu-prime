## 0. 一句话

**记忆是一张有向加权图，同时也是一张循环神经网络。**
节点是记忆单元；两点之间存两条边，每条边是一个**矢量**：方向由这条边自己学出来，大小代表「想起 A 时有多容易想起 B」；
边权由语义相似、共同出现、先后顺序三股力量合成，再乘上随时间衰减、随反复提及而放慢衰减的时间权重。
一串联想走下来，各步矢量按权重相加得到合矢量；走熟的路径会长出一条**直接指向终点**的捷径边，而走过的每一步都作为路径记录保存，不被压缩掉。
回忆有两种走法：不知道终点时做扩散激活；知道大致终点时顺着方向导航。

## 1. 要解决的问题

纯向量检索（RAG）的三个短板：

| 短板 | 例子 | AGM 的对应 |
|---|---|---|
| 只认字面相似，不认联想 | 问「奶奶家的院子」，召不回「外婆做的桂花糕」 | 共现边 + 扩散激活 |
| 没有方向 | 「咖啡→出门」和「出门→咖啡」一样强 | 每对节点两条方向相反的矢量边，大小各自学习 |
| 只有终点没有过程 | 想起了结论，说不出是怎么想到的 | 捷径指向终点 + 中途路径完整保留（§3A） |
| 没有时间与固化 | 三个月前提过一次的事和天天提的事同等对待 | 幂律遗忘 + 间隔效应固化 |

设计目标：**可解释**（每次召回能给出路径）、**可本地运行**（单机 SQLite + 向量索引）、**在线学习**（每次写入与召回都更新图，不需要离线重训才能用）。

## 2. 数据模型

### 2.1 节点 `v_i`
| 字段 | 含义 |
|---|---|
| `content` | 原文（一段对话、一个事实、一个概念） |
| `kind` | `episode`（情景）/ `fact`（事实）/ `concept`（抽象概念，由睡眠期聚类生成） |
| `e_i ∈ R^d` | 内容嵌入（可选，只用来找召回起点，§5） |
| `z_i ∈ R^d` | 结构向量：图神经网络聚合邻居后的上下文向量（§4.2） |
| `t0, t_last` | 创建时间、最近一次被提及或召回的时间 |
| `n_i` | 被提及次数 |
| `s_i ≥ 0` | 固化强度（§3.3） |
| `salience_i` | 写入时的重要度（情绪、用户显式标记、出现「记住」之类的说法） |

### 2.2 矢量边 `(i → j)`
同一对节点存两条边，**方向各自独立学习**（不要求 `û_ji = −û_ij`），**大小不同**（`w_ij ≠ w_ji`）。
```
边矢量  v_ij = w_ij · û_ij，   û_ij ∈ R^k 单位矢量（k 默认 16），每条边一个，独立更新
```
大小 `w_ij` 由下面四个分量合成（§3.1）：

| 分量 | 符号 | 来源 | 对称？ |
|---|---|---|---|
| 语义相似 | `c_ij = cos(e_i, e_j)` | 向量 | 对称 |
| 赫布共现 | `h_ij ∈ [0,1)` | 同时被激活 | **非对称**（先激活者→后激活者更强） |
| 时序邻接 | `τ_ij ∈ [0,1]` | 写入顺序 | **非对称**（前向 1.0，后向 0.4） |
| 类型关系 | `r_ij` | 可选：因果、属于、反义… | 按类型定义 |

每个节点出边上限 `M_out`（默认 32），保证图稀疏。

## 3. 权重公式

### 3.1 联想权重（边的有效强度）
```
W_ij(t) = σ( α·c_ij + β·h_ij + γ·τ_ij + b_type(r_ij) + b ) · D_j(t)
```
`σ` 是 sigmoid，保证 0~1；`D_j(t)` 是目标节点的时间权重。四个系数 α β γ b 既可手设，也可由 §4.3 的学习头从召回反馈里学。

### 3.2 时间权重（幂律遗忘）
```
D_j(t) = (1 + (t − t_last_j) / τ0) ^ (−ψ_j)，   ψ_j = ψ0 / (1 + κ·s_j)
```
选幂律而非指数：心理学里长时遗忘更接近幂律（Wixted & Ebbesen 1991），尾部更长，旧记忆不会掉到 0。
固化强度 `s_j` 越大，指数 `ψ_j` 越小，曲线越平。

### 3.3 固化权重（反复提及 + 间隔效应）
每次提及或成功召回：
```
s_j ← s_j + η_s · (1 − exp(−Δt / τ_s))，   n_j ← n_j + 1，   t_last_j ← t
```
`Δt` 是距上次提及的时间。连续刷屏（Δt 很小）几乎不加分；隔一段时间再提起加分多——就是间隔效应。
`s_j ≥ θ_fix` 视为**已固化**：不参与剪枝，衰减极慢，进入长期记忆层。

「反复提及」的判定：新写入与已有节点向量相似度 ≥ `θ_merge` 时，不新建节点，而是给旧节点做一次固化更新。

### 3.4 赫布更新（联想如何长出来）
节点 i、j 在同一次召回或同一段对话里被激活（激活值 a_i、a_j）：
```
Δh_ij = η_h · a_i · a_j · (1 − h_ij) − λ_h · h_ij        （i 先于 j）
Δh_ji = η_h · ρ · a_i · a_j · (1 − h_ji) − λ_h · h_ji      （反向只得 ρ 比例，默认 0.4）
```
`(1 − h)` 让它饱和，`λ_h` 是自然衰退。先后顺序带来的非对称和脉冲时序可塑性（STDP）是同一个思路。

## 3A. 矢量与路径：指向终点，保留中途

### 3A.1 一条路径的三个量
路径 `P = (i0 → i1 → … → in)`，第 t 步的边强度 `w_t`、方向 `û_t`：
```
合矢量   R(P) = Σ_t w_t · û_t                   （按权重加权的方向和）
路径强度 S(P) = Σ_t w_t · w_t / Σ_t w_t         （按权重加权：强的一步分量大）
直度     φ(P) = |R(P)| / Σ_t w_t  ∈ [0, 1]       （1 ＝ 各步同向，思路笔直；越小越绕）
```
方向不再由位置推出，所以合矢量**不会自动**指向终点；指向终点靠下面两条机制得到。

### 3A.2 路径保留
每次召回或导航实际走过的路径都存成**路径记录**：
```
path = { id, nodes:[i0…in], uses, t_last, s, R, S, φ }
```
各步的 w 与 û 在边上，路径记录只引用它们，所以任何时候都能拆回每一步，也能按当前边值重算 R、S、φ。路径也有固化强度 `s`，规则同 §3.3。

### 3A.3 捷径边：直接指向终点
同一路径被走满 `n_short` 次（默认 3），在起点和终点之间长出一条捷径边：
```
v_shortcut = S(P) · R(P)/|R(P)|，   shortcut.path = P.id
```
- 捷径的**终点就是路径终点**，方向就是这条路径合矢量的方向，大小是路径强度：一步指向终点；
- 捷径只引用路径，不替代路径；
- 路径中任何一步的边变了，依赖它的捷径标为**过期**，下次使用前按路径重算。

### 3A.4 方向怎么学
- 初始化：随机单位矢量；有内容嵌入时可用嵌入差的投影作初值；
- **顺路拉直**：每走一次路径 P，各步方向朝 R(P) 的方向转一小步
  `û_t ← normalize((1 − η_dir)·û_t + η_dir·R̂(P))`，常走的思路越走越直（φ → 1），合矢量越来越可靠地代表「往终点的方向」；
- **赫布**只改大小 w（§3.4），**方向学习**只改 û，两者分开。

### 3A.5 回路残差：发现矛盾的联想
方向独立学习后，闭合回路 `C` 的合矢量不再恒为 0：
```
ρ(C) = |Σ_{e∈C} v_e| / Σ_{e∈C} w_e
```
ρ≈0 表示这一圈联想互相一致；ρ 大表示几条边「指的方向对不上」，作为矛盾候选交给睡眠期复核（§6）。这是 v0.3 选独立方向的主要收益。

### 3A.6 已知缺陷：加权强度会掩盖薄弱一环（读数 §10A-5）
按权重加权时，弱的一步自己的权重也小，对 S 的影响被压低：中间一步从 0.8 降到 0.1，S 只从 0.869 降到 0.858，最优路径仍然经过这条几乎断掉的边。
候选修正（待定问题 6）：
- (a) 加权强度乘一个断链闸：`S'(P) = S(P) · min(1, min_t w_t / θ_link)`，任一步低于 θ_link 就按比例压低；
- (b) 加权的权重不用 w 本身，改用时间权重或固化强度：`S = Σ λ_t w_t / Σ λ_t`，`λ_t = D_t · (1 + s_t)`；
- (c) 保持现状，只在导航时把 `w < θ_link` 的边视为不可走。

## 4. 神经网络结构

AGM 里有三层「网络」，从无需训练到需要训练逐级叠加，任何一层缺席系统仍可用。

### 4.1 第一层：图本身就是循环网络（不需要训练）
召回 = 扩散激活：
```
x   = 种子激活（查询向量与节点向量的相似度，取前 K_seed 个）
a⁰  = x
aᵏ⁺¹ = topk( (1 − δ) · Wᵀ aᵏ + x )        k = 0 … L−1
score_j = a_j^L · D_j(t) · (1 + μ·s_j)
```
`δ` 是泄漏，`+x` 是每步把查询重新注入（防止激活跑偏），`topk` 是侧抑制。
L 默认 3 步。这在形式上就是一个以 W 为权重矩阵、带输入注入的离散 Hopfield / 循环网络。
**可解释性**：每个被召回节点都能回溯出贡献最大的激活路径（`explain` 接口），并存成路径记录（§3A.2）。

**导航模式**（已知终点时）：
```
有未过期捷径 → 直接用，并附上它引用的完整路径
否则         → 以 S(P) 为分数做最优优先搜索（深度 ≤ 5），返回终点 + 完整路径，并记为路径记录
```
扩散激活回答「想到了什么」，导航回答「怎么从这里想到那里」。

### 4.2 第二层：图神经网络编码器（离线训练，可选）
给每个节点算一个结构向量：
```
z_i = LayerNorm( e_i + Σ_j  W_ji · φ(e_j) )      φ = 两层 MLP，GraphSAGE 式聚合，两跳
```
用途：(1) 向量检索时同时查 `e`（字面）和 `z`（联想上下文），扩大种子覆盖；
(2) 链接预测：`p(i→j) = σ(z_iᵀ A z_j)`，给出「可能有关但还没连上」的候选边，**只作为低权重潜在边**，被真实共现证实后才转正。

### 4.3 第三层：召回打分头（在线学习）
一个小 MLP，输入 `[c_ij, h_ij, τ_ij, D_j, s_j, a_j^L, cos(q, z_j)]`，输出最终分数。
训练信号来自用户行为：召回结果被引用、被追问、被纠正。对比损失（InfoNCE）：被用到的为正例，同批没被用到的为负例。
冷启动时退化为 §4.1 的公式打分。

## 5. 内容嵌入（可选）

矢量化的主体在 §3A。这里的句向量嵌入只做两件事：给召回找起点、给边方向做初值。没有嵌入模型时系统照样运行（起点改用关键词匹配）。

| 对象 | 方案 |
|---|---|
| 内容向量 `e` | 可插拔句向量模型。默认本地中文模型（如 bge-small-zh，512 维）；接口只要求 `encode(text) → R^d` 并归一化 |
| 结构向量 `z` | §4.2 GNN 输出，同维度，便于同一索引混查 |
| 查询向量 | 同一模型编码；对话场景把最近 3 轮拼成上下文再编码 |
| 索引 | HNSW（M=16, ef=64）；节点数 < 5 万时直接暴力余弦即可 |
| 压缩 | int8 标量量化，内存约为 float32 的 1/4；召回后用原向量重排 |
| 版本 | 每个向量记 `encoder_id`；换模型时后台逐批重编码，新旧混查期间按 `encoder_id` 分开索引 |

## 6. 生命周期

```
写入 remember
  文本 → 切分 → 编码 e
       → 与最近邻比较：≥θ_merge ⇒ 固化旧节点（§3.3）；否则新建节点
       → 连边：语义近邻 top k_link 双向各一条 + 时序前驱（前向 1.0 / 后向 0.4）
       → 与当前对话里已激活的节点做赫布更新（§3.4）

召回 recall
  查询 → 编码 → 向量种子 → 扩散激活 L 步 → 打分 → 返回 top k + 解释路径
       → 被返回且被使用的节点：固化 +1 次；它们之间：赫布更新

睡眠 sleep（定时，例如每天一次，离线）
  1 衰减：W 低于 ε 且两端都未固化的边删除；孤立且 D<ε 的情景节点归档
  2 重放：取近期 salience 高的节点，模拟召回一遍，强化它们之间的边
  3 抽象：在情景节点上做社区发现（Leiden），每个稳定社区生成一个 concept 节点，
          内容为摘要，连「属于」边；概念节点天然高固化
  4 重训：用当天反馈小步更新 §4.2 / §4.3 的参数
```

## 7. 接口

和 LSPI 保持同一种调用形态：`call(op, action=None, **args) -> dict`，结果统一用 `ok` 判断。

| op | action | 说明 |
|---|---|---|
| `remember` | `add`（默认）/ `batch` | 写入；返回 `node_id`、是否合并、固化值 |
| `recall` | `query`（默认）/ `explain` | 召回 top k；`explain` 返回激活路径 |
| `navigate` | `to`（默认）/ `direction` | 给终点或方向，返回终点 + 完整路径 + 合矢量 |
| `path` | `get` / `list` / `shortcuts` | 读路径记录、列出捷径及其是否过期 |
| `associate` | `link` / `unlink` / `neighbors` | 手动建边、删边、看邻居（双向分开列） |
| `reinforce` | `mention` / `feedback` | 显式固化；召回反馈（用到 / 没用到 / 纠错） |
| `forget` | `soft` / `hard` | 软删（权重清零、可恢复）/ 硬删（含向量） |
| `sleep` | `run` / `dry_run` | 睡眠维护；`dry_run` 只出报告 |
| `stats` | — | 节点、边、固化分布、索引状态 |

## 8. 存储与复杂度

- SQLite：`nodes`、`edges(src, dst, c, h, tau, r, updated_at)`（主键 `(src,dst)`，正反两条各一行），出边和入边各建索引；向量另存 `.npy` + HNSW 文件。
- 写入：O(log N)（ANN）+ O(k_link)。
- 召回：O(log N) + O(L · K · M_out)，默认 3 × 8 × 32 ≈ 800 次边计算，与总规模 N 基本无关。
- 规模目标：单机 100 万节点、3000 万条边内，召回 < 50 ms（待 G3 实测）。

## 9. 参数表（默认值，即原型取值）

| 参数 | 默认 | 含义 |
|---|---|---|
| `τ0` | 1 天 | 遗忘时间尺度 |
| `ψ0` | 0.5 | 未固化时的遗忘指数 |
| `κ` | 1.0 | 固化对遗忘的减速系数 |
| `η_s`, `τ_s` | 1.0, 1 天 | 单次固化增益、间隔效应时间尺度 |
| `θ_fix` | 3.0 | 固化阈值 |
| `θ_merge` | 0.92 | 「反复提及」合并阈值（须按所用编码器重新校准，见 §10 读数 4） |
| `α, β, γ, b` | 2, 4, 1, −2 | 联想权重系数 |
| `η_h, λ_h, ρ` | 0.3, 0.01, 0.4 | 赫布学习率、衰退、反向比例 |
| `k_link, M_out` | 4, 32 | 写入连边数、出边上限 |
| `L, δ, K` | 3, 0.5, 8 | 扩散步数、泄漏、侧抑制保留数 |

## 10. 原型读数（`python TanPowasd/agm/agm_proto.py`，原始输出 `agm/readings_v0.1.json`）

原型只用标准库，向量用字符 n-gram 哈希代替句向量模型，所以只验证**公式的行为方向**，不代表正式系统的效果。

1. **方向性**：先写「早上煮咖啡」再写「出门赶地铁」→ `W(咖啡→地铁)=0.2564`，`W(地铁→咖啡)=0.1533`。前向是后向的 1.67 倍。
2. **遗忘与固化**：只提过一次的节点 vs 在第 2/6/14/30 天各被提一次的节点（s=3.846，已固化）：

   | 距最近一次 | 1 天 | 10 天 | 100 天 |
   |---|---|---|---|
   | 只提过一次 | 0.707 | 0.302 | 0.100 |
   | 反复提及 | 0.931 | 0.781 | 0.621 |
3. **间隔效应**：同样复习 4 次，集中（每 0.1 天）s=0.381，间隔（每 2 天）s=3.459，相差 9 倍。
4. **反复提及合并**：「我住在法兰克福」×2 合并成一个节点（n=2，s=0.95）；带句号的第三条相似度只有 0.89，低于 0.92，**没合并**。说明合并阈值必须按实际编码器校准，哈希向量对标点太敏感——这是原型暴露的真问题，正式系统用句向量模型并在 G1 标定。
5. **联想召回**：查询「奶奶家的院子」，「外婆做的桂花糕」与它的字面相似度只有 0.167。
   - 纯向量：院子、地铁换乘路线、夏天的蝉鸣（**召不回**桂花糕）
   - 扩散激活（两者共现过 4 次）：院子、**外婆做的桂花糕**、公司周会纪要
   - 第三名「公司周会纪要」是噪声：原型对所有节点对都算了边，没有做 `M_out` 稀疏化和最小权重截断。正式实现只在真实存在的边上扩散。

### 10A. v0.3 矢量读数（`python TanPowasd/agm/agm_vector.py`，原始输出 `agm/readings_v0.3_vector.json`）
链：家 → 院子 → 桂花树 → 桂花糕（另有 家→厨房→桂花糕、家→地铁→公司），k=8，方向随机初始化。

1. **正反边独立**：`|v(树→糕)|=0.9`，`|v(糕→树)|=0.3`，正反方向余弦 −0.083（不再强制相反）。
2. **路径强度**：按权重加权 S=0.8692（对照：相乘 0.648，算术平均 0.8667）；学习前直度 φ=0.562。
3. **越走越直**：同一路径走 5 次，φ 依次 0.733 → 0.843 → 0.909 → 0.948 → 0.971。
4. **捷径指向终点**：第 3 次后长出 家→桂花糕 捷径，方向与路径合矢量余弦 1.000000，w=0.8692，路径记录仍在。
5. **中途变弱**：院子→桂花树 从 0.8 降到 0.1，捷径过期被检出并重算，但 S 只降到 0.8579，最优路径仍走这条线——即 §3A.6 的缺陷。
6. **回路残差**：方向首尾一致的回路 ρ=0.0；随机方向回路 ρ=0.4281。

## 13. 风险与对策

| 风险 | 对策 |
|---|---|
| 扩散激活把噪声也放大（读数 5 已见） | 出边上限、最小权重截断、每步重注入查询、侧抑制 |

| 合并阈值误合并两件不同的事 | 合并前比对时间与实体，冲突则建新节点并连「相似」边；保留合并日志可撤销 |

## 14. 与现有工作的关系

- **ACT-R 激活方程**：基础激活 ln(Σ t^−d) 与本提案的幂律遗忘同源；AGM 把它放到边上而不只在节点上。
- **SM-2 / FSRS**：间隔重复的调度模型，E2 用它做对照。
- **GraphRAG、HippoRAG**：都用图辅助检索；HippoRAG 用个性化 PageRank 扩散。AGM 的差别是边**有方向、带时间衰减和固化、在线赫布学习**，图会随使用持续变化。
- **TransE 一类知识图谱嵌入**：把关系当作平移（h + r ≈ t）；AGM 的边方向不绑定节点位置，而是每条边独立学、顺路拉直，大小是可塑的联想强度，并且保留整条路径。
- **大脑库（dsh-memory）**：AGM 独立设计，不依赖它；G6 之后可作为一个可选的召回插件对接，届时另立任务。
