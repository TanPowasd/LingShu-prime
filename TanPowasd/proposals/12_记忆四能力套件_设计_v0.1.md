# 记忆四能力套件：检索 · 联想 · 推理 · 自主学习 —— 设计 v0.1（2026-10-13）

目标：系统与测评一起做。每项能力 = 一个模块 + 一个基准 + 一个守卫（断言 + `--mutate` 定点变异），先在 LingShu-prime 落地，再按 dsh-memory「一个 PR 只做一件」拆成四个 PR。

| 能力 | 模块（起点） | 基准 | 主指标 | 反面对照 |
|---|---|---|---|---|
| 检索 | QMD（agm/confluence/qmd.py；dsh-memory 移植 md_cg/qmd.py） | hive 主轮 92 题（检索面 + 端到端）、LoCoMo dev | 8000 字召回、端到端覆盖率 | BM25 / TriCue v3 / 直读 |
| 联想 | 汇流图扩散（近义/谓词/出处边，只连不合并）+ 中枢抑制；对照 Liyang 中文联想通路 | 自建合成集：线索与目标记忆**零词面重合**，只靠图上一跳/两跳可达；另取 hive「状态归属」题 | r@5、r@10 | BM25 应≈0（证明不是词面命中）；打乱边后应掉到基线 |
| 推理 | 链式组合：两跳追问 + ChronicleDM 状态链（时点/变更/缘由） | hive「缘由 / 变更 / 时点 / 历史」子集；LoCoMo 多跳与时序类 | 子集端到端覆盖率、编造数 | 单跳 QMD；去掉时间边 |
| 自主学习 | 巩固：作答后把被判官确认的事实回写成新边，检索权重按命中反馈在线调整；无标签时只用自洽信号 | 在线流：同一语料按时间分前后两半，后半题测「学过 vs 冻结」 | 后半覆盖率差值 | 打乱反馈应无增益；冻结臂 |

## 共同纪律
- 选型只在 dev 上做，冻结配置写 PREREG 后才看留出集；未胜项如实保留。
- 判官不带 system；带 key 的跑法遵守 APPROVAL（LLM 接入优化类常设许可），报告调用数与失败数。
- 零 key 读数先出，带 key 端到端后出。

## 顺序
1. 检索：dsh-memory PR 已备（分支 feat/qmd-multidim-retrieval，365364d），待 fork 推送。
2. 联想：先造合成集与守卫，再接图扩散。
3. 推理：切 hive / LoCoMo 子集，复用两跳与 ChronicleDM。
4. 自主学习：在线流基准 + 回写巩固。
