相对上次推送版（Liyang/ = rel-v1.1，LingShu-prime 5c89cd1 / 发布树 rel-v1@0778413）的增量升级：只动版本链（`lingshu_ng/chain/`，`enable_chain` 仍为可选、缺省关）。

## 改了什么
- **v13.1 零 LLM 抽取（版本链开启时缺省生效，`LINGSHU_NG_CHAIN_V13=1`）**
  - 速记体抽取（shorthand.py，chain-r10/r11 起逐步加入）：中英夹杂速记、键值/秒数/函数签名等取值形态、数值等值写法（千分位、单位换算）归一。
  - 账本上下文「主体 属性 值」抽取（sav.py，chain-r13）：渠道前缀剥离（「群机器人：」「Re:」「[标签]」等）、无动词「S A V」与「切到/按…走」类句式，只用已确认的锚点（lex 确认实体/属性 ∪ 句式路径登记 ≥2 的属性），结果不回灌锚点。
  - 冷启动待查队列：锚点增长后重试本命名空间未登记句（每命名空间 ≤300）。
  - v13.1 收紧（chain-r13 事后，为误登记）：冷启动中文取值只给 lex 确认的（主体, 属性）；主体须在词界起；锚定事件的中文取值不重取。开关 `LINGSHU_NG_CHAIN_V13_COLDCJK` / `_BOUND` / `_BACKLOG`。
  - 写入期零 LLM；`LINGSHU_NG_CHAIN_V13=0` 时与 v12 逐条相同。
- **B：受限 LLM 抽取（可选，缺省关，`LINGSHU_NG_CHAIN_LLM=1`）**（llm_extract.py，chain-r12 起）
  - 只在「事件信号 + 句中同现已登记实体与其属性」时触发，补抽规则无结果/锚定拒收的句子、复核可疑规则结果；字段逐字子串校验、取值过共用归一；失败退回规则结果。
  - 需要 OpenAI 兼容端点与 key（`LINGSHU_NG_LLM_KEY` 或 `CLINE_API_KEY`）；未配置或调用失败时等同 v13.1。
