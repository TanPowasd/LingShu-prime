## 4. 区间算法（写死，不许执行者自选）

| 项 | 冻结值 |
|:--|:--|
| 方法 | 按独立场景聚类的配对差 percentile bootstrap ✔ |
| 聚合顺序 | 题目加权分(0–100) → 同 pair 的 P−B → 场景内对重跑等权平均 → 场景加权均值 → 有放回重采场景 ✔ |
| 场景权重 | 〔待定：`equal` 或 `item_weight`。重判显示两者对结果影响大（考卷 B dsh：−1.3 vs −7.3 分），必须冻结前选定；起草建议 `equal`（独立单位是场景，按场景等权与"场景＝独立样本"一致）〕 |
| B | 10,000 ✔ |
| RNG | SplitMix64（γ=0x9E3779B97F4A7C15），种子 = SHA-256(utf-8(analysis_id)) 前 8 字节无符号大端 ✔ |
| 下标映射 / 抽取顺序 | floor((x>>11)·2⁻⁵³·G)；b 外层、场景内层 ✔ |
| 百分位 | Hyndman–Fan type 7（线性插值），2.5% 与 97.5% ✔ |
| 置信水平 | 95% ✔ |
| analysis_id 模板 | `pes/memory/v1/{experiment_id}/{plugin}@{version}-vs-B0/{taskset_sha12}` 〔冻结时确认；一经登记不得改，改即新分析〕 |
| 单组成功率 | Clopper–Pearson 精确区间，仅题目可视为独立时；0 成功报"0/k + 95% 上限" ✔（差距分析 §9-C4 待裁决） |
| 库 | 主实现纯 Python 标准库；参考实现 numpy（版本写入 manifest）✔ |

## 5. 停止规则

| 项 | 草案值 |
|:--|:--|
| 独立单位 | 不同事实组合/项目/叙事的场景；同一份历史内的卡/题/依赖簇**不是**独立场景 ✔ |
| 固定样本 | 独立场景数 S 〔待填，≥8〕× 每场景配对重跑 R 〔待填，≥3〕，测试前写入 `sample_plan`，一次性完成后判定 ✔ |
| 配对重跑的含义 | 每次从基线快照恢复并经独立检查后，B0 与 P 各完整跑一遍（写入 + 召回 + 作答 + 判分）；只重采生成器不算 ✔ |
| 外部故障补跑上限 | 每个 pair 〔待填，建议 2 次〕；整对作废、整对补跑，不只补一边 ✔ |
| 达到上限仍不完整 | 停止该批、记录阻塞；`verdict_v3` 返回"实验无效/待重跑"（`SAMPLE_PLAN_INCOMPLETE`），不缩小分母、不换容易场景 ✔ |
| 精度不足 | 半宽 >5 → ❓，不续采；续采须另立协议 ✔ |
| 安全中止 | 优先于样本计划 ✔ |

## 6. 五状态映射（数值化）

| 项 | 草案值 |
|:--|:--|
| a（最小有意义提升） | +5 分（启动试跑候选，校准后冻结） |
| b（可接受退化） | 5 分 |
| 精度门槛 | 半宽 (U−L)/2 ≤ 5 分 |
| 有效样本门槛 | 场景 ≥8 且每场景有效配对重跑 ≥3；不足 → ❓ |
| 映射 | 精度与样本满足时：L>a ✅；U<−b ❌；L>−b 且 U<a ➖；其余（含端点等于门槛）❓ ✔ |
| 运行层 | 证据缺/哈希不符/判分器撤销/算法未校验/NaN/L>U → 待验证/待修复；计划内缺有效配对 → 实验无效/待重跑 ✔（差距分析 §9-C1 待裁决） |
| 没法测 | 安装失败（同时记"安装环节 ❌失败"）/ 环境不支持 / 任务不适用，分别记录 ✔ |
| 发布 | 题集冻结、本规范冻结、算法回归通过、证据完整、独立复核、场景可分组全部满足才"正式"；否则"方法试验" ✔ |
