## 环境
见 `_公共环境.md`；全新临时 HOME，安装前快照 0 文件 ⟦录像:dsh_install@00:00#3⟧。

## 复现步骤
1. 全新 HOME：clone、按 README 签令牌、启动 `python3 -m md_cg.mcp_server`（通用 MCP 宿主路径，非 DSH）、做一次 ingest + recall、停服务。
2. 按常识"卸载"：删除 clone 目录与 venv（README 无卸载说明）。
3. 列出 HOME 下与 `/tmp/md_cg_servers/` 下的新增文件。

## 期望
README 有卸载章节，列出程序会写的所有位置（含 HOME 下的令牌库/主密钥、缓存、临时文件）及清理命令；进程退出时清理自报文件；非 DSH 宿主不写 DSH 专属目录。

## 实际
- README 无卸载章节 ⟦录像:dsh_install@00:23#75⟧。
- 删除 clone + venv 后残留（不计 npm 缓存与 `MDCG_ROOT` 用户数据）⟦录像:dsh_install@00:23#78⟧ ⟦录像:dsh_install@00:23#79⟧：
  - `~/.dsh/.dsh-memory/`：18 个文件，约 2.0 MB（包内 data 被复制进 HOME；本机**不是** DSH 宿主）
  - `~/.mdcg/`：`_tokens.json`（含令牌）、`_tokens.json.lock`、`master.key`、`sustain`、`theory.json`
  - `/tmp/md_cg_servers/<pid>.json`：每次服务启动一个（约 520 字节），进程退出不删
  - 另：npx 缓存约 70 MB（`~/.npm/_npx` 与 `_cacache`，属 npm 行为，仅提示）

## 影响
用户"卸载"后 HOME 下仍留有效令牌与主密钥；`/tmp/md_cg_servers/` 随启动次数累积。

## 建议
- README 增"卸载"节：停服务 → 删 clone/venv → 按需删除 `~/.mdcg/`（提示其中有令牌与主密钥，删除即失去私密记忆）→ `~/.dsh/.dsh-memory/` → `/tmp/md_cg_servers/`；`MDCG_ROOT` 是否删由用户决定。
- 服务退出（含 SIGTERM）时删除自己的 `/tmp/md_cg_servers/<pid>.json`；启动时清理已不存在 pid 的陈旧文件。
- 仅在检测到 DSH 宿主时写 `~/.dsh/…`，或在 `--show-config` 中列出所有写入路径。
