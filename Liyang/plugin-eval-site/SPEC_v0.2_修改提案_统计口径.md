> 状态：**提案**。按 SPEC §9 走 7 天征求意见；v0.1 原文不动。实现已就绪但缺省未启用（`classify(..., ci_method="item")` 仍为缺省）。

## 背景（一段话）

考卷 B 的 89 卡里有 11 组共用同一答案键（独立答案键 76 个）。按答案键整簇重抽后，三组已发结论都不翻转，区间变宽 4%～14%，有效样本量 65～82。但复核同时发现：①"≥3 道题"是绝对门槛，剔题后口径不一致；②BM25 的 ❌ 只在折合计分下成立，只按 strict 计分为 0；③至少一个对比（dsh vs BM25，去脏卡）的区间下界恰为 0，边缘结论随实现细节翻转。

## 提案

| # | 条款 | v0.1 现状 | v0.2 提议 | 理由 / 证据 | 对已发结论的影响 |
|--:|:--|:--|:--|:--|:--|
| P1 | §6 区间 | 配对 bootstrap **按题**重抽 | **按答案键簇重抽**（簇＝上游 `answer_group`；上游未给时用 `(file, answer.human.line)`），B=10,000、rng 种子 7 不变；同时公开按题区间作对照 | 89 卡非独立（U3）；按题区间偏窄约 12%（dsh/BM25） | 无翻转（dsh 😐、BM25 ❌、jaccard 😐） |
| P2 | §6 报告字段 | 无 | 报告必须写**独立题数与有效样本量 n_eff**（CR1 设计效应） | 读者需要知道"89 题"实为约 65 题的证据量 | 仅增加披露 |
| P3 | §6 效应门槛 | "净提升 ≥ 3 道题"（绝对） | 改为"**≥ 3/89 每题**（≈0.034），按实际计分卡数折算"；全卷 89 卡时与 v0.1 等价 | 剔脏卡、剔分歧题、换卷时绝对门槛口径漂移（BM25 去分歧题后 -2.8 题/54 卡＝-4.7 题/89 卡，绝对门槛下判 😐） | 全卷结论不变 |
| P4 | §6 稳健性面板 | 严格档仅"存档对照" | 每个 ✅/❌ 必须附**稳健性面板**：①严格档合并；②只按 strict 计分；③去掉判官分歧题。**✅/❌ 须在主口径与①下同时成立**；②③不改结论，但若②或③不成立，结论后加注"（对计分口径敏感）"并写明哪一项 | 判官合并规则是本站自选口径，结论不应依赖它；②③反映"伤/帮在哪一档"，对读者有信息量 | BM25 ❌ 保留，加注"对计分口径敏感：只按 strict 为 0；去判官分歧题后 😐" |
| P5 | §6 边缘带 | 无 | 区间端点距 0 不足 0.25 题（约 2 倍蒙特卡洛误差）时，用 B=100,000 复算；仍贴边则判 😐 并注"边缘" | dsh vs BM25 去脏卡下界 = 0；B=10,000 端点误差约 ±0.1 题 | 无已发结论受影响（该对比非结论） |
| P6 | §6 多口径 | 无 | 敏感性/附录口径里出现的 ✅/❌ **不得**进入一句话结论或排名；需下一轮预登记后重测 | jaccard 附录臂只按 strict 时 ✅，属事后多口径之一 | 无（jaccard 本就不进结论） |

**不提议改动**：种子数 3、"各种子方向一致"一条、判官达标线、"≥3 题"的量级本身（dsh 对比的簇稳健标准误约 2.2 题，3 题≈1.4 个标准误；它本来是"超出判分噪声带"的最小报告单位，与统计显著性由区间一条分开把关，量级仍合理）。

## 需征求意见的问题

1. P1 的簇定义是否应改用更粗的"同文件、断点相距 < N 行"（相邻断点的卡也相关，但不同键）？本站倾向等上游 `answer_group` 字段（UPSTREAM U3），不自造。
2. P4 中"只按 strict"是否应升格为与折合并列的**第二条能力轴**（类似依据轴，单列不合成）？
3. P3 改为比例门槛后，换卷（考卷 A 184 题）时是否仍沿用 3/89，还是按各卷判官噪声重新标定？
4. （P7，考卷 A 新增）考卷 A 的簇用上游 hmb 依赖簇（`独立性分析.py`，Jaccard≥0.5＝24 簇）是否定为判定口径？阈值 0.4 只有 9 簇时百分位 bootstrap 机械给出下界 0，是否应规定"簇数 < 20 时改用簇级符号检验/置换检验"？读数见 `reports/稳健性复核_考卷A.md`。
