## 改了什么
- **v15 零 LLM 抽取（版本链开启时缺省生效，`LINGSHU_NG_CHAIN_V15=1`；=0 时与 v13.1 逐条相同）**（新文件 `lingshu_ng/chain/v15.py` + `ledger.py` 钩子）
  - **消息体外壳重抽**：规则、锚定、「主体 属性 值」三条路径都没登记的句子，去掉消息体外壳后再抽一次（quote 仍存原句）。外壳包括句首「【…】」「[…]」「（…）」标签、「标签：」、时间戳、
    约定式提交头 `fix(S):`（括号里的作用域当主体）、`git commit -m`、转述头（「客户提到」「对方确认」）、口语起头（「嗯，」「那个，」）、`@提及`、包着中文的反引号；同时规范千分位和空格键值（`conn_limit 72`→`conn_limit=72`）。
    markdown 列表、引用行和「…说：」这类标签不剥。重抽结果要过三道门：主体必须是账本里已知的名字，取值不能是单字，取值形态要和这个属性已登记的多数形态一致。
  - **后修**：主体带句首标签的去掉标签；千分位被截断（`25,200`→`25`）、键值丢了数、「定下来了，是 V」把「下来」当值，这几种只在原句有直接证据时修；
    属性名后面带残片（之争/这件事/本轮/变更通知/由原值…）的截回已确认属性；「落点/去向/方位」归到「位置」（本命名空间登记过位置时）；有「未定」信号又有两值信号、却只判了单值的事件，按属性取值形态取两个值改判 unresolve。
  - 写入期零 LLM。可选开关：`LINGSHU_NG_CHAIN_V15_GA` / `_GE` / `_LEARN` / `_FINAL`（缺省 off / 1 / full / 0）。
- B（受限 LLM 抽取，`LINGSHU_NG_CHAIN_LLM=1`）不变，仍缺省关。
