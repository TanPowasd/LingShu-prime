# BENCH_WORLD · 世界渲染正确性 / 反投影 / 耗时对比（旧 world3d vs ng）

复现：`python tests_ng/world/bench_world.py`（约 70 s，2 核 aarch64）→ 本目录 `BENCH_WORLD.json`。
种子 20261009，画幅 320×240，每组 24 个随机相机位姿（look-at 绕场景中心，仰角/距离/fov 随机），每帧取 3 次中位耗时。

## 对比对象

| 列 | 代码 | 说明 |
|---|---|---|
| 旧 · 上游 2bb8291 | `/workspace/work/ls/upstream` | 画家算法，物体按**世界 z** 排序，部件按定义序，无背面剔除，反投影忽略位姿 |
| 本仓 lingshu/（现状） | 本仓 `lingshu/world/world3d.py` | 已含 world-02/03/06/n1/n2 修复：相机深度排序 + 部件最近点排序 + 背面剔除；仍为画家算法 |
| 修补版 integrated-v2 | `/workspace/work/ls/integrated` | 在上一列基础上再修 #221（天空物体地平线钳制改为屏幕像素比较） |
| **ng** | `lingshu_ng/world/compat.World3D` → `raster.rasterize` | z-buffer，单一相机来源 |

## 方法

- **真值**：`tests_ng/world/oracle.py` 逐像素中心射线–三角形求交（Möller–Trumbore，双面，不剔除），与任何光栅器无共享代码；
  只共享 `camera.pixel_rays`。场景只用盒（含桌椅的盒/柱部件），所以各实现的几何是**精确同一多面体**，没有曲面细分差异。
- **同一口径**：四个实现一律「渲染 RGB → 最近调色板色（含旧版 0.6/0.85/0.95/1.15 着色与 ×0.7 描边变体）→ 标签」，再与真值比。
  组合形状按「物体 × 颜色组（桌面/椅面+靠背 vs 腿）」打标签，所以「后腿盖住桌面」这类部件序错误可见。
- **内部像素**：剔除真值 3×3 邻域内标签不一致的轮廓带——消除像素中心约定（PIL 整数坐标 vs ng 的 +0.5）带来的 1px 边缘差，
  只留下真正的**遮挡/排序**错误。「全部像素」口径照列，但其中旧实现有一部分是边缘约定差，ng 与真值同约定所以为 0，不应据此夸大。
- **共面 z-fighting**：两张桌子桌面等高时重叠区真值不唯一（射线到两面等距），这些像素（组合形状组每帧平均 ≈293 px）对所有实现一律剔除。
- **反投影**：每个位姿 10 个天空物体（balloon，真实宽 0.5 m），真值 3D 点在屏幕内均匀取像素、深度 3–30 m，
  按相似三角形合成 bbox → `add_vprim` → 量 3D 误差与同一相机重投影误差。每次用新的 `World3D`（避免同类合并）。
  「地平线以上/以下」按 bbox 中心是否在屏幕上 45% 区域划分——旧实现对天空物体有「不低于地平线」的启发式钳制。

**读数要点**
- ng 在三组共 72 个位姿上**内部像素遮挡错误 = 0、错物体像素 = 0**；且同约定下全部像素也逐像素等于真值。
- 旧画家算法的错误有两类根源：(1) 排序键写错（上游用世界 z：A′ 组 14/24 场景出错，修复后降到 2/24）；
  (2) **结构性无解**——互相穿插的物体不存在正确的全序（A 组修补版仍有 21/24 场景、重叠区 7.47% 像素画错物体），
  部件最近点距离也只是启发式（B 组修补版仍 15/24 场景出错，最差 1.75%）。z-buffer 对两类都免疫。
- **代价：耗时**。numpy z-buffer（行区间双区间 + 批量三角形系数）仍比 PIL C 实现的多边形填充慢约 2–5 倍（0.9–1.2 ms vs 0.22–0.52 ms / 帧，320×240；上一版为 4.4–8.9 ms）。
  对当前用途（离线场景图、测试、每帧几十个物体）可接受；若进实时循环可换 C 后端，接口不变。

## 模拟 / 世界模型 / 多视角 / 锚点（本仓旧 lingshu.world vs ng）

由 `tests_ng/world/bench_world_sim.py` 生成（`BENCH_WORLD.json` 的 `sim` 段；两边同进程、同种子 20261009、每项 40 个随机场景）。

| 指标 | 旧（本仓 lingshu/world） | **ng** |
|---|---|---|
| 影子重放 exact 预测最大偏差（follow+seek 追逐，150 tick，共 12000 次） | 0.0 m / miss 0 | 0.0 m / miss 0 |
| seek 静止目标：距离序列翻转次数（越过目标来回振荡） | 7453 | 0 |
| seek 静止目标：200 tick 后仍未到达（>0.0075 m）的场景 | 40/40 | 0/40 |
| 换 seed 后物理世界演化不同：SevenLayerLoop / UnifiedWorldModel / WorldLearner | 否 / 否 / 否 | 是 / 是 / 是 |
| 多视角：同类 2 物体 × 2 视角 → 融合物体数（真值 2） | 1.0 | 2.0 |
| 多视角：3D 误差中位 / 最大 | 2.6636 / 5.0619 m | 0.0048 / 0.0077 m |
| 锚点图：叠放判「支撑」、并排不判「支撑」的准确率（80 对） | 0% | 100% |
| 耗时：SpacetimeConsistency.step_verified（10 实体） | 0.077 ms | 0.212 ms |
| 耗时：UnifiedWorldModel.verify_run(1)（10 实体） | 0.516 ms | 0.704 ms |
| 耗时：SevenLayerLoop.step（6 实体） | 0.098 ms | 0.228 ms |

**读数要点**
- 影子对齐两边都是 0：旧实现的世界与影子是**两份手抄的同一（有缺陷的）公式**，彼此一致；问题在于世界一修（seek/follow 截断），
  影子就分叉（旧 spacetime + ng 世界时 follow 偏差 0.46 m，即旧 F 组失败）。ng 两侧只调用 `scene_sim.deterministic_dir/apply_move`，
  结构上不存在第二份公式。
- 旧 seek 以「单位方向 × speed」步进，永远越过目标再折返（40/40 场景振荡、7 千余次翻转）；ng 步长截断到剩余距离，零翻转、全部到达。
- 旧三处构造方都不把 seed 传给物理世界，seed 维度消融实验无效；ng 全部透传（缺省 42 与旧轨迹逐位一致）。
- 旧多视角只按类别合并、`merge_dist` 形参未使用：两把椅子被三角化成一个点（中位误差 2.66 m）；ng 按射线几何分轨，误差 ≈5 mm
  （全部来自 0.01 m 取整）。另防近平行射线与「同机位两射线交于光心」的伪解。
- 旧「支撑」判据写反（同高并排判支撑、叠放判相邻），准确率 0%；ng 按足迹重叠 + 顶底接触判定。
- **代价**：ng 模拟侧约慢 1.4–2.8 倍（每步 0.2 ms 量级）：确定性步长走 numpy 版 `sim.seek_step`、观测入口做 isfinite 校验。
  绝对值仍远低于渲染（~1 ms/帧），未做优化。
